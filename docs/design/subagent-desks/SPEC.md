# 서브에이전트 임시 책상 디자인 메모

- **대상:** developer (T2). T2가 이 문서의 절 번호(§1–§8)를 인용합니다.
- **입력:** 지시서 `.superpowers/sdd/2026-10-15-subagent-desks/brief.md`(사용자 승인 설계), progress.md의 T1d·B171·B172, Phase 1 디자인 4.4·5.1·5.2·7장·10장, Phase 4a 디자인 §2(셔터).
- **재사용:** 토큰·스프라이트·책상 SVG(`viewBox 0 0 24 30`)·이름표(`.nametag`)·이름표 아래 두 줄(`.desk-meta`)·빈 의자(`empty-chair`)·타이핑 애니메이션(`state-working`)·`.chip`은 지금 것을 그대로 씁니다. **새 토큰과 아이콘은 없습니다.**
- 문구는 끝의 문구표가 기준이고, 코드에 넣기 전에 qa 검토를 거칩니다(팀 규칙 9). 렌더 확인은 T3에서 합니다.

---

## §1 자리

- 리드 책상 **바로 오른쪽**에 묶음 하나(`.sub-desks`)로 둡니다. 순서: 리드 → 임시 책상 묶음 → 팀원 책상(지금 순서 그대로).
- `.sub-desks`: `display: flex; flex-wrap: wrap; gap: 8px; align-items: flex-end; margin-left: -8px`. 책상 사이 기본 간격(20px)보다 좁혀 리드에 딸린 묶음으로 읽히게 합니다(리드와의 거리 12px).
- `subagents`가 비었거나 없으면 묶음을 그리지 않습니다(빈 자리를 남기지 않음).
- 끝난 층(`ended`)에는 그리지 않습니다(살아 있는 층만 수집).

## §2 크기

| 항목 | 값 |
|---|---|
| 책상 SVG | 같은 `viewBox 0 0 24 30`을 **72×90px**로(도트 1칸 3px — 리드·팀원 책상 4px의 3/4, 정수 배율이라 도트가 흐려지지 않음) |
| 책상 상자(`.desk--sub`) | 폭 76px(테두리 포함) |
| 이름표·두 줄 | 최대 폭 70px |

## §3 테두리와 "임시" 표시

- 테두리: 책상 상자에 **2px 점선 `--muted`**, 안쪽 여백 `4px 2px 2px`. 리드·팀원 책상에는 테두리가 없어서 점선 상자 하나로 구별됩니다(점선 = 잠깐 있는 것. 종료됨 칩의 점선과 같은 말).
- "임시" 표시: 상자 왼쪽 위 모서리에 걸친 작은 딱지 `.sub-tag` — `position: absolute; top: -8px; left: 4px`, 배경 `--wall`(방 벽과 같아 테두리가 끊긴 것처럼 보임), 글자 10px `--muted`, 여백 `0 3px`. 글자 문구표.
- 색에만 의존하지 않기: 점선 모양과 "임시" 글자가 구별을 맡습니다.

## §4 책상 안

| 상태 | 그림 |
|---|---|
| 일하는 중(`working: true`) | 캐릭터 `BODY_A`/`BODY_B` 타이핑 프레임(`state-working`, 지금 팀원과 같은 애니메이션), 모니터 켜짐(`--green`). 셔츠 색 `--muted`(#9d97c7) — 역할색(리드 보라·개발 초록·리뷰 하늘·기타 노랑)과 겹치지 않음. 상태 말머리(⌨·z z)는 그리지 않습니다(책상이 작고, 리드 말풍선이 하는 일을 이미 보여 줌) |
| 끝남(`working: false`, 끝나고 30초 안) | 빈 의자(`empty-chair`, 지금 퇴근 모양), 모니터 꺼짐. 책상 상자 전체 `opacity: .55`. 첫째 줄 끝에 `· 끝남`(§5) |
| 휴업 층(멈춤) | `working`과 무관하게 빈 의자, 모니터 꺼짐, 애니메이션 없음. 셔터(Phase 4a §2)는 지금처럼 방 위 66%를 덮고 임시 책상도 그 뒤에 있습니다 |

- 권한 정책 자물쇠·결정 `?`·점선 링은 임시 책상에 그리지 않습니다(누를 수 없는 책상, 정책은 리드 패널의 "서브에이전트" 절).
- 움직임 줄이기: 전역 규칙으로 타이핑 프레임이 멈춥니다(Phase 1 10장).

## §5 이름표와 두 줄

```
┌ ─ ─ ─ ─ ─ ─ ┐  ← 2px 점선 --muted, 왼쪽 위에 [임시]
  (72×90 책상)
  API 문서 조…    ← .nametag: 맡긴 일(description), 11px, 말줄임
  Explore         ← .desk-meta 1줄: 종류(agentType)
  sonnet · 12.3k  ← .desk-meta 2줄: 모델 · 토큰
└ ─ ─ ─ ─ ─ ─ ┘
```

| 줄 | 내용 | 값이 없을 때 |
|---|---|---|
| 이름표 | `description`(줄바꿈·연속 공백은 공백 하나로). CSS 말줄임(`.nametag`, 최대 70px) | 종류를 씁니다. 종류도 없으면 문구표 "이름 없음" |
| 1줄 | `agentType` | 문구표 "종류 없음" |
| 2줄 | `{모델} · {토큰}` — 모델은 지금 책상과 같은 `modelLabel`, 토큰은 `formatTokens` | 모델이 없으면 토큰만. 둘 다 없으면 줄을 그리지 않음 |

- 두 줄은 지금의 `.desk-meta`(10px `--muted`, 줄마다 말줄임) 모양 그대로입니다. 지금 책상은 모델과 토큰을 각각 한 줄로 두지만, 임시 책상은 첫 줄에 종류가 들어가므로 둘째 줄에서 `·`로 잇습니다.
- 끝남이면 1줄이 `{종류} · 끝남`입니다(문구표).

## §6 툴팁과 접근성

- **누를 수 없는 책상**입니다. `<div class="desk desk--sub" role="img" aria-label="…">`, `tabindex` 없음(포커스를 받지 않음), `aria-haspopup` 없음, `cursor: default`. 호버해도 말풍선(`ActivityBubble`)을 띄우지 않습니다 — 서브에이전트가 한 일은 지금처럼 리드 말풍선에 합쳐 보입니다(Phase 1 7.1·Phase 3 §6.3 그대로).
- 툴팁: 상자에 `title`(문구표 "툴팁"). 맡긴 일 전체와 종류·모델·토큰.
- `aria-label`(문구표): 스크린 리더는 둘러보기에서 이 그림을 읽습니다. 맡긴 일 전체를 넣습니다(화면의 말줄임과 무관).
- Tab 순서는 바뀌지 않습니다(리드 책상 다음은 곧바로 팀원 책상).

## §7 4개 넘으면 `+N`

- 임시 책상은 **최대 4개**. 고르는 순서: 일하는 중이 먼저, 그 안에서는 먼저 시작한 것부터(끝남은 그 뒤, 먼저 끝난 것부터). 순서가 스냅샷마다 흔들리지 않게 서버가 준 순서를 이 규칙으로 한 번 정렬합니다.
- 5개 이상이면 넷째 책상 뒤에 칩 `.sub-more`: `.chip` 모양, 테두리 점선 `--muted`, 글자 11px `--muted`, `align-self: center`. 글자 `+{N}`(N = 전체 − 4). `role="img"`, `aria-label`과 `title`은 문구표.
- 칩도 누를 수 없습니다(포커스 없음).

## §8 좁은 화면 배치

- **900px:** 방 폭(약 790px)에 리드 96 + 묶음(76×4 + 8×3 = 328) + 칩 + 팀원 책상이 한 줄에 들어가고, 넘치면 Phase 1 5.5대로 다음 줄로 꺾입니다.
- **360px:** 방 안쪽 폭이 약 290px라 리드 다음 줄로 묶음이 통째로 내려가고, 묶음 안에서 셋째 책상까지(76×3 + 8×2 = 244) 한 줄, 넷째와 칩이 다음 줄입니다. 묶음은 `flex-wrap: wrap`이라 가로 스크롤이 생기지 않습니다. `margin-left: -8px`는 줄이 바뀌어도 왼쪽 여백(`.desks` padding 8px) 안이라 넘치지 않습니다.
- 창문 그림은 720px 이하에서 지금처럼 숨습니다.

## 문구표

`{…}`는 바뀌는 값입니다. 모두 qa 검토 대상입니다(스펙에 글자가 정해진 문구 없음).

| 위치 | 문구 |
|---|---|
| 딱지 | `임시` |
| 이름 없음(맡긴 일·종류 모두 없음) | `서브에이전트` |
| 종류 없음(1줄) | `종류 모름` |
| 끝남(1줄 끝) | `{종류} · 끝남` |
| 2줄 | `{모델} · {토큰}` (예 `sonnet · 12.3k`) |
| 툴팁 `title` · 일하는 중 | `맡긴 일: {맡긴 일 전체}` 줄바꿈 `{종류} · {모델} · 토큰 {토큰}` |
| 툴팁 `title` · 끝남 | 위와 같고 둘째 줄 끝에 ` · 끝남` |
| `aria-label` · 일하는 중 | `임시 책상, 서브에이전트 {종류}, 맡긴 일: {맡긴 일 전체}, {모델}, 토큰 {토큰}` |
| `aria-label` · 끝남 | `임시 책상, 서브에이전트 {종류}, 맡긴 일: {맡긴 일 전체}, 끝남` |
| `+N` 칩 글자 | `+{N}` |
| `+N` 칩 `aria-label`·`title` | `서브에이전트 {N}개 더` |

값이 없을 때: 맡긴 일이 없으면 `맡긴 일: …` 조각을 빼고, 모델이 없으면 `{모델}, ` 조각을 뺍니다. 토큰이 0이고 모델도 없으면 토큰 조각을 뺍니다.
