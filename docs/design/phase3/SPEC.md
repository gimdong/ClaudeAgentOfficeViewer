## §0 새 토큰과 아이콘

**색의 뜻:** 권한 정책은 **보라(`--violet`, #b98cff)**입니다. 결정 보고서(노랑)·진단(하늘)과 같은 자리의 서랍이라 테두리 색으로 구별합니다. 보라는 리드의 셔츠 색이기도 하지만 화면 장식(테두리·칩)에는 아직 쓰지 않았으므로 겹치지 않습니다. 값의 색은 `항상 질문` = `--yellow`(묻는 것은 결정 대기와 같은 노랑), `금지` = `--pink`(위험), `기본` = `--ink`입니다.

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `--policy` | `var(--violet)` | 패널·목록 서랍 테두리, HUD 버튼, 자물쇠, 종류 칩 |
| `--pick` | `#1c1a2c` | 고른 값의 배경. Phase 1 8.2 선택지 상자의 "선택" 배경과 같은 값을 이름만 붙인 것 |

### 1.3 본문 공통

- 스크롤 영역: `.rp-scroll` 값(`flex:1; overflow-y:auto; padding: 0 14px 16px`).
- 절: `.rp-sec` 값(위아래 12px, 사이 1px 점선 `--desk`), 절 제목 11px `--muted`.
- 절 순서: (화면에 없는 이름 안내) → 횟수 → (others 안내) → 바로 쓰는 묶음 → 도구별 권한 → (서브에이전트). 안내 두 가지와 횟수는 하나의 절 안에 줄로 쌓습니다(절 제목 없음).

### 1.4 화면에 없는 이름 안내

목록에서 [고치기]나 [대상 추가]로 연 대상이 **지금 어느 층에도 없는 이름**이면 맨 위에 한 줄을 둡니다. `--font-text` 13px `--ink`, 왼쪽 2px `--policy` 막대, 안쪽 왼쪽 여백 10px. 문구 §8.2.

리드(`lead`)와 `others`는 이름이 아니므로 이 안내를 두지 않습니다. 서브에이전트 종류는 지금 보이는 리드의 `subTypes`에 없으면 둡니다.

### 1.5 횟수 줄

- 문구: 「스펙」 `켠 뒤로 금지 {n}번 · 질문 {n}번`. 12px `--font-pixel` `--ink`, 숫자 그대로(쉼표 넣음, 예 `1,204번`).
- **둘 다 0이면** `켠 뒤로 막거나 물은 적 없음`(12px `--muted`).
- 한쪽만 0이어도 두 값을 모두 씁니다(`켠 뒤로 금지 0번 · 질문 5번`). 줄 모양이 매번 같아야 읽기 쉽습니다.
- 바로 아래 10px `--muted`로 `대시보드를 다시 켜면 0부터 셉니다`를 늘 둡니다(서버 메모리 값, 스펙 7.3).
- **[범위 A]** `금지`가 빠지면 `켠 뒤로 질문 {n}번`.
- **"그 밖의 모든"(`others`) 패널에는 횟수 줄과 보조 줄을 두지 않습니다.** 횟수는 막힌 에이전트 자신의 키로 쌓이므로 `others`에는 거의 쌓이지 않아, 늘 0으로 보여 오해를 삽니다(B95).

### 1.6 `others`를 따를 때

`member.policy.source === "others"`(자기 규칙이 없고 `others`의 규칙을 따르는 중)이면 횟수 줄 아래에 둡니다.

- 문구: 「스펙」 `정한 것이 없어 "그 밖의 모든"을 따릅니다` (`--font-text` 13px `--ink`, 왼쪽 2px `--policy` 막대).
- 그 아래 링크 모양 버튼(`.rp-more` 모양, 색 `--cyan`) `"그 밖의 모든" 정책 보기` — 누르면 같은 서랍이 `others` 대상으로 바뀌고 ‹가 생깁니다(→ 원래 대상).
- 권한 칸(§2)의 처음 값은 **모두 `기본`**입니다(자기 규칙이 없음). 여기서 하나라도 정해 저장하면 이 이름은 더 이상 `others`를 따르지 않습니다. 이것을 권한 칸 바로 위에 12px `--muted`로 알립니다(문구 §8.2 "others 경고").
- 리드는 `others`를 따르지 않으므로(Global Constraints) 리드 패널에는 이 절이 없습니다.

## §2 권한 칸

### 2.1 바로 쓰는 묶음(템플릿)

| 요소 | 값 |
|---|---|
| 절 제목 | `바로 쓰는 묶음` |
| 버튼 | `읽기 전용` **[범위 A]** · `명령은 물어보고` **[범위 C: 리드 아닌 대상에서 숨김]** · `제한 없음`. 도트 버튼(`.pbtn`, 28px, 12px), 사이 6px, 줄바꿈 허용(`flex-wrap: wrap`) |
| 설명 | 버튼 아래 12px `--muted` `--font-text`: `누르면 아래 칸이 모두 그 조합으로 바뀝니다. [저장]을 눌러야 적용됩니다.` |
| 동작(B80) | 일곱 줄 **전체**를 그 조합으로 바꿉니다. 조합에 없는 줄은 `기본`. 요청은 보내지 않습니다 |
| aria | 버튼의 접근 이름은 글자 그대로. `aria-describedby`로 위 설명 줄을 연결합니다 |

템플릿 이름은 저장하지 않으므로 "지금 어느 템플릿인지" 표시는 하지 않습니다.

### 2.2 일곱 줄

순서: `명령 실행` · `파일 고치기` · `웹 접근` · `팀원·서브에이전트 만들기` · `외부 도구(MCP)` · `그 밖의 도구` · `모든 도구` (서버 `GROUP_KEYS` 순서).

마크업(줄 하나):

```html
<fieldset class="pr-row" role="radiogroup" aria-label="명령 실행">
  <span class="pr-name" aria-hidden="true">명령 실행</span>
  <label class="pr-opt pr-opt--default"><input type="radio" name="pr-bash" value="default"><span class="pr-mark" aria-hidden="true"></span>기본</label>
  <label class="pr-opt pr-opt--ask"><input type="radio" name="pr-bash" value="ask"><span class="pr-mark" aria-hidden="true"></span>항상 질문</label>
  <label class="pr-opt pr-opt--deny"><input type="radio" name="pr-bash" value="deny"><span class="pr-mark" aria-hidden="true"></span>금지</label>
</fieldset>
```

**격자(FB-6: 행과 열을 모두 적습니다. 열을 auto로 두지 않습니다):**

| 선택자 | 값 |
|---|---|
| `.pr-row` | `display: grid; grid-template-columns: minmax(0, 1fr) 52px 84px 52px; grid-template-rows: auto; column-gap: 4px; align-items: center; margin: 0; padding: 4px 0; border: 0; min-width: 0` |
| `.pr-name` | `grid-column: 1; grid-row: 1;` 12px `--ink`, `overflow-wrap: anywhere` (긴 묶음 이름은 두 줄로 꺾임) |
| `.pr-opt--default` | `grid-column: 2; grid-row: 1` |
| `.pr-opt--ask` | `grid-column: 3; grid-row: 1` |
| `.pr-opt--deny` | `grid-column: 4; grid-row: 1` |

- `fieldset`은 브라우저 기본 `min-inline-size: min-content`가 있어 격자가 넘칠 수 있으므로 `min-width: 0`을 반드시 줍니다.
- 열 폭은 고정이라 일곱 줄의 값 열이 세로로 정확히 맞습니다. 열 폭은 Galmuri11 12px 기준 `항상 질문`(5자)이 여백 포함 84px 안에 들어가는 값입니다. 정적 렌더(§9)에서 넘치면 이 값을 고칩니다.
- **[범위 A]·[범위 C]**로 값이 빠지면 그 `label`만 그리지 않고 열 정의는 그대로 둡니다.

**값 상자 `.pr-opt`:**

| 상태 | 모양 |
|---|---|
| 평소 | 높이 28px, `display:flex; align-items:center; justify-content:center; gap:4px`, 2px `--desk` 테두리, 12px `--muted`, `cursor: pointer`, `white-space: nowrap` |
| 호버 | 테두리 `--cyan` |
| 고름 (`:has(input:checked)`) | 배경 `--pick`, 글자 굵게(700), 테두리와 글자가 값의 색: `기본` `--ink` / `항상 질문` `--yellow` / `금지` `--pink` |
| 포커스 (`:has(input:focus-visible)`) | 상자에 전역 포커스 링(`outline: 2px solid var(--focus); outline-offset: 2px`) |

- **색에만 의존하지 않기:** 고른 상자에는 표시 칸 `.pr-mark`(6×6, 글자 왼쪽)를 값의 색으로 **채우고**, 고르지 않은 상자의 표시 칸은 1px `--muted` 테두리만 있는 빈 칸입니다. 글자 굵기도 바뀝니다. 흑백으로 봐도 어느 값을 골랐는지 보입니다.
- `input`은 화면에서 숨기되 포커스는 받게 둡니다: `position:absolute; opacity:0; width:1px; height:1px; margin:0`(`display:none`이나 `visibility:hidden`은 키보드로 고를 수 없게 되므로 쓰지 않습니다). `label`에 `position: relative`.

**바꾼 줄 표시:** 저장된 값과 다른 줄은 줄 왼쪽에 2px `--yellow` 막대를 둡니다(`.pr-row.changed { box-shadow: inset 2px 0 0 var(--yellow); padding-left: 6px }`). 글자 안내는 §2.4의 아래 고정 줄이 맡습니다.

### 2.3 "모든 도구" 줄

- 일곱째 줄 위에 1px 점선 `--desk`(위 여백 4px)를 그어 앞의 여섯 줄과 나눕니다.
- 줄 바로 아래 12px `--muted` `--font-text`: `"모든 도구"는 위에서 기본으로 둔 도구에 적용됩니다.`
- 그 아래 같은 모양으로 예외 설명(문구 §8.2). 스펙 5.2와 B94의 빼는 도구 여덟 개(`AskUserQuestion`, `ExitPlanMode`, `SendMessage`, `TaskCreate`·`TaskUpdate`·`TaskList`·`TaskGet`, `SubagentHandback`)를 사람의 말로 묶은 것입니다. `모든 도구`를 `금지`로 둔 사람이 "그럼 보고도 못 하나" 걱정하지 않게 합니다.
  - 문장이 길어 서랍 폭(본문 400px)에서 두세 줄로 꺾입니다. `--font-text` 12px, 줄 간격 1.6, `overflow-wrap: anywhere` 없이 **단어 단위로**(`word-break: keep-all`) 꺾습니다. 위 "모든 도구" 설명과의 사이 4px. 폭 360px에서는 네 줄까지 됩니다(§9 7-11).
- `fieldset`의 `aria-describedby`로 첫 줄을 연결합니다.

### 2.4 저장 (아래 고정 영역)

| 요소 | 값 |
|---|---|
| 영역 | `flex: none; display: flex; align-items: center; gap: 10px; padding: 10px 14px; border-top: 2px solid var(--desk); background: var(--panel)` |
| 상태 줄 | 왼쪽, `flex: 1; min-width: 0`, `--font-text` 13px, 줄바꿈 허용. 아래 표 |
| [저장] | 오른쪽, `.pbtn--primary`, 높이 36px, 여백 `0 16px`, 13px. 바꾼 것이 없으면 `aria-disabled="true"`(포커스는 받음, 눌러도 요청 없음) |

| 상태 | 언제 | 상태 줄(색) | [저장] | `role` |
|---|---|---|---|---|
| 같음 | 편집 값 = 저장된 값 | 비움 | `aria-disabled` | 없음 |
| **바꿈** | 하나라도 다름 | `저장하지 않은 변경이 있습니다` (`--yellow`, 글자만) | 활성 | 없음. [저장]의 `aria-describedby`로 연결 |
| 저장 중 | PUT 중 | 그대로 | `disabled`, 글자 `저장하는 중…`(Phase 2 §6.2와 같은 말) | 없음 |
| 저장됨 | `"saved"` | `저장했습니다` (`--green`). 다음에 값을 바꾸면 사라짐 | `aria-disabled` | 없음. live region 문장 §8.6 |
| 값이 올바르지 않음 | `"invalid"`(400) | §8.3 (`--red`) | 활성 | `alert` |
| 대상이 너무 많음 | `"limit"`(400 `{"reason":"limit"}`, 대상 200개) | §8.5의 상한 문구 (`--red`) | 활성 | `alert` |
| 저장하지 못함 | `"failed"`(네트워크, 5xx) | §8.3 (`--red`) | 활성 | `alert` |
| 지금만 적용됨 | `"not-persisted"`(200 `saved:false`, B87) | §8.3 (`--yellow`, 2–3줄) | **활성**(`aria-disabled` 아님). 값이 서버와 같아도 누를 수 있고, 누르면 같은 규칙으로 다시 PUT합니다(파일 저장 재시도) | `alert` |

- 저장 실패는 네 가지(값이 올바르지 않음, 대상이 너무 많음, 저장하지 못함, 지금만 적용됨)이고, 모두 서랍을 닫지 않고 고른 값을 그대로 둡니다(스펙 7.1). `"invalid"`는 400 중 `reason`이 `limit`이 아닌 것입니다.
- **모두 `기본`으로 저장**하면 빈 `rules`를 보내 그 대상이 지워집니다. 상태 줄은 `저장했습니다` 대신 `정책을 지웠습니다`, live region은 §8.6의 "지움" 문장입니다.
- 편집 값은 서랍을 열 때와 대상이 바뀔 때, 저장에 성공했을 때만 서버 값으로 채웁니다. 3초마다 오는 스냅샷은 편집 값을 건드리지 않습니다(Review Focus 1).
- **저장하지 않고 떠날 때:** 바뀐 값이 있는 채로 서랍을 닫거나(×, Esc, 다른 서랍 열기) 대상을 옮기면(‹, 서브에이전트 고르기, "그 밖의 모든" 보기) 편집 값을 버리고 live region에 `저장하지 않은 변경을 버렸습니다`를 넣습니다. 확인 창은 띄우지 않습니다(비모달 서랍의 흐름을 끊지 않음). 버리기 전의 경고는 위의 노란 상태 줄이 맡습니다.

서브에이전트는 리드 책상에 합쳐 그려지므로(Phase 1 7.1), 리드 패널의 권한 칸 아래에 둡니다. 팀원 패널에는 없습니다.

| 요소 | 값 |
|---|---|
| 절 제목 | `서브에이전트` |
| 설명 | 12px `--muted` `--font-text`: `리드가 띄운 서브에이전트는 리드 책상에 함께 보입니다. 종류마다 따로 정할 수 있습니다.` |
| 종류 버튼 | 리드 `member.subTypes`마다 하나. `.pbtn` 28px, 글자 = 종류 이름(최대 폭 100%, 넘치면 말줄임, `title`에 전체). 그 종류에 규칙이 있으면 글자 앞에 `lock` 아이콘(`--policy`). `flex-wrap: wrap`, 간격 6px |
| 그 밖의 모든 | 종류 버튼 뒤, 같은 모양: `그 밖의 모든 팀원·서브에이전트`. `others`에 규칙이 있으면 `lock` 아이콘 |
| 보이는 종류가 없음 | 종류 버튼 대신 12px `--muted`: `지금 보이는 서브에이전트가 없습니다. 정책 목록의 [대상 추가]로 미리 정할 수 있습니다.` (그 밖의 모든 버튼은 그대로) |
| 누르면 | 같은 서랍이 그 대상(`sub:<종류>` 또는 `others`)으로 바뀝니다. 머리는 그 대상 기준(§1.2), ‹가 생기고 ‹는 리드로 돌아갑니다. 포커스는 제목으로. 바꾼 값이 있었으면 §2.4의 "떠날 때" 규칙 |
| 버튼 aria-label | `{대상 화면 이름} 권한 정하기` (예 `서브에이전트(Explore) 권한 정하기`) |

`sub:`·`others` 패널에는 서브에이전트 절이 없습니다(한 단계만 들어갑니다).

### 4.2 대상 행

행 순서: `lead` → `agent:*`(이름순, `localeCompare(…, "ko")`) → `sub:*`(이름순) → `others`. 저장된 모든 대상이 나옵니다(지금 화면에 없는 이름 포함).

**`리드`와 `그 밖의 모든` 행은 규칙이 없어도 늘 둡니다**(B95). 규칙이 없으면 요약은 `정한 것 없음`, 버튼은 [고치기]만 두고 [지우기]는 두지 않습니다(지울 것이 없음). 규칙이 있으면 다른 행과 같이 [지우기]도 둡니다. HUD 개수(§5)는 **저장된 대상만** 셉니다.

마크업: `<ul class="pl-rows">` 안의 `<li class="pl-row">`.

**격자(행·열 모두 명시):**

| 선택자 | 값 |
|---|---|
| `.pl-row` | `display: grid; grid-template-columns: minmax(0, 1fr) max-content; grid-template-rows: auto auto; column-gap: 10px; row-gap: 2px; align-items: center; padding: 8px 10px; border: 2px solid var(--desk); margin-bottom: 4px` |
| `.pl-name` | `grid-column: 1; grid-row: 1;` 이름 13px `--font-text` 700 `--ink`, `overflow-wrap: anywhere`(100자도 전부 보임) + 뒤에 6px 띄워 종류 칩(§1.2 모양, 11px) |
| `.pl-sum` | `grid-column: 1; grid-row: 2;` 요약 12px `--font-text` `--muted`, `overflow-wrap: anywhere` |
| `.pl-act` | `grid-column: 2; grid-row: 1 / 3; display: flex; gap: 6px; align-self: center` |
| `.pl-err` (지우기 실패 문구, §4.3) | `grid-column: 1 / 3; grid-row: 3;` 위 여백 4px. 문구가 있을 때만 셋째 행이 생깁니다(`grid-template-rows: auto auto`에 없는 행은 암묵 행 `auto`로 생기지만, 열은 위처럼 명시합니다) |

- 이름: 대상 화면 이름(§8.1). 리드는 `리드`, 그 밖의 모든은 `그 밖의 모든 팀원·서브에이전트`. 종류 칩이 이름과 같은 말이면(리드, 그 밖의 모든) 칩을 두지 않습니다.
- 화면에 없는 이름이면 이름 뒤 칩 다음에 10px `--muted` `지금 없음`을 붙입니다.
- 요약: §8.4 규칙.
- [고치기]: `.pbtn` 28px. 그 대상의 에이전트 패널(§1)을 엽니다. 목록 서랍은 닫히고 패널 머리에 ‹(→ 목록)가 생깁니다. aria-label `{대상 화면 이름} 정책 고치기`.
- [지우기]: `.pbtn .pbtn--danger` 28px, `trash` 아이콘. aria-label `{대상 화면 이름} 정책 지우기`.

### 4.4 빈 목록

저장된 대상이 하나도 없어도 고정 두 행(`리드`, `그 밖의 모든 팀원·서브에이전트`, 둘 다 `정한 것 없음`)은 보입니다. 빈 목록 문구(§8.4)는 **두 행 사이가 아니라 두 행 아래, [대상 추가] 위**에 한 줄로 둡니다: 12px `--font-text` `--muted`, 왼쪽 정렬, 위아래 여백 8px(`.dp-state`의 가운데 정렬·24px 여백은 쓰지 않습니다 — 행이 있는 목록 안의 안내이므로). 이름 있는 대상이 하나라도 생기면 이 문구는 사라집니다. 한계 줄은 그대로 보입니다.

순서: 한계 줄 → `리드` 행 → `그 밖의 모든` 행 → 빈 목록 문구 → [+ 대상 추가]. (대상이 있을 때는 `리드` → 이름 있는 대상들 → `그 밖의 모든` → [+ 대상 추가])

### 4.5 대상 추가 **[범위 B]**

목록 맨 아래 `[+ 대상 추가]`(`.pbtn`, `plus` 아이콘). 누르면 버튼 자리에 칸이 펼쳐집니다(`aria-expanded`). 칸 테두리 2px `--desk`, 안쪽 10px.

```
종류   (●) 팀원  ( ) 서브에이전트
팀원 이름 [ reviewer               ]
팀원 이름은 화면의 이름표와 같게 적어 주세요.
(틀린 이름 안내)
                         [취소] [열기]
```

| 요소 | 값 |
|---|---|
| 종류 | `fieldset` + `legend` `종류`(11px `--muted`). 라디오 두 개 `팀원` / `서브에이전트`(§2.2의 `.pr-opt` 모양, 너비는 글자대로). 처음 값 `팀원` |

| 도움말 | 12px `--muted`: 팀원 `팀원 이름은 화면의 이름표와 대소문자까지 같게 적어 주세요.` / 서브에이전트 `서브에이전트 종류는 Explore처럼 대소문자까지 같게 적어 주세요.` |

## §6 표시

### 6.1 버튼이 된 책상

결정이 없는 책상도 `<button type="button" aria-haspopup="dialog">`입니다(Ruling B83). `OpenPolicyContext`가 없으면 지금처럼 `div`.

| 항목 | 결정 없음 | 결정 대기 |
|---|---|---|
| 누르면 | 에이전트 패널 | 결정 보고서(지금처럼) |
| 이름표 | 지금 그대로(배경 없음) | 노랑(지금 그대로) |
| 이름표 호버·포커스 힌트 | ` · 열기` (지금 결정 책상과 같은 말) | ` · 열기` |
| QRING | 없음 | 호버·포커스일 때(지금 그대로) |
| 호버 | `cursor: pointer`. 이름표에 1px `--policy` 밑줄(`text-decoration: underline; text-underline-offset: 2px`) | 지금 그대로 |
| aria-label | §8.7 | §8.7 |

- 대상 키가 될 수 없는 이름(101자, 제어 문자, 예약어)의 책상을 누르면 `그 밖의 모든` 패널이 열립니다. 화면의 `targetKeyOf`는 서버와 같은 규칙(B75)을 씁니다. 따로 안내 문구는 두지 않습니다(패널 제목이 `그 밖의 모든 팀원·서브에이전트`라 보임).

말풍선(호버·포커스)과 Tab 순서는 지금 그대로입니다. 퇴근(`offline`) 책상도 버튼입니다(정책은 이름 기준이라 퇴근한 팀원에게도 걸 수 있음).

### 6.2 자물쇠

`member.policy`가 있으면(`own`이든 `others`든) 책상 SVG에 `LOCK_DESK`(§0)를 그립니다.

| 항목 | 값 |
|---|---|
| 자리 | 책상 SVG(viewBox `0 0 24 30`)의 **(18, 3)**, 5×6 = 20×24px. 오른쪽 위, 모니터(y 11부터) 위. 상태 말머리(x 1–12), ?(x 3–8), QRING(x 1–10)과 겹치지 않습니다 |
| 요소 | `<g data-testid="lock" class="lock">` |
| 색 | §0 표 |
| 퇴근·종료 층 | 그대로 그립니다(종료 층의 흑백 필터가 함께 걸림) |
| 움직임 | 없음. 결정 ?와 박자를 다투지 않게 정적입니다 |
| aria | 책상 aria-label에 `, 권한 정책 있음`을 더합니다(§8.7). 자물쇠 `g`는 SVG가 `aria-hidden`이므로 따로 이름이 없습니다 |

### 6.3 정책으로 막힘 **[범위 A]**

서버가 30초 동안 `member.policyDenied`를 싣습니다(B85).

| 자리 | 모양 |
|---|---|
| 자물쇠 | `LOCK_DESK_DENIED`(§0): 분홍 + 오른쪽 느낌표(모양으로도 구별). 깜빡이지 않음 |
| 책상 aria-label | `, 방금 정책으로 막힘`을 더합니다(§8.7) |
| 말풍선 첫 줄 | 아이콘 `lock`(선·강조 `--pink`, 강조 `a`는 `--panel`) + 「스펙」 `정책으로 막힘: {묶음 화면 이름}`. 테두리는 `--cyan` 그대로(결정이 아님, `decision: false`) |
| 말풍선 보조 줄 | 지금 규칙 그대로(`metaLine`). 막힌 것이 서브에이전트면 `policyDenied.subType`으로 앞머리 `서브에이전트({종류}) · `를 붙입니다(Phase 1 7.1과 같은 규칙) |
| 우선순위 | 결정 대기 → **정책으로 막힘** → (그 밖은 Phase 1 7.2 순서) |
| 손 | 들지 않습니다. `desk--decision`, ?, 노란 이름표 모두 없음 |

말풍선은 호버·포커스일 때만 보이므로, 보지 않는 사람에게는 느낌표 달린 분홍 자물쇠가 30초 동안의 신호입니다. 자세한 뜻(어느 묶음인지)은 말풍선 글자로 전합니다(책상 포커스 → `aria-describedby="say"`).

### 6.4 결정 보고서

| 요소 | 값 |
|---|---|
| "권한" 버튼 | 보고서 머리 `.rp-meta` 줄의 **맨 끝**(`margin-left: auto`). 높이 22px, 여백 `0 6px`, 2px `--policy` 테두리, 배경 없음, 11px `--ink`, `lock` 아이콘 12px + `권한`, 사이 4px. 호버 테두리 `--ink`. `.rp-nav`(‹ › ×)에 넣지 않습니다 — 좁은 폭에서 제목 자리를 줄이지 않으려는 것입니다 |

## §7 포커스와 서랍 관계

### 7.1 한 번에 하나

결정 보고서(노랑)·진단(하늘)·에이전트 패널(보라)·정책 목록(보라)은 같은 자리의 서랍이고 **한 번에 하나만** 열립니다. 하나를 열면 다른 것은 애니메이션 없이 바로 닫히고, 닫힌 쪽의 "연 요소"로 포커스를 되돌리지 않습니다(Phase 2 §5). 패널에 바꾼 값이 있었으면 §2.4의 "떠날 때" 문장을 알립니다.

### 7.2 포커스

| 때 | 포커스 |
|---|---|
| 패널을 열 때(책상, 보고서 "권한", 목록 [고치기], [대상 추가]의 [열기]) | 제목 `#ap-title` |
| 패널 안에서 대상이 바뀔 때(서브에이전트 고르기, "그 밖의 모든" 보기, ‹) | 바뀐 대상의 제목 `#ap-title` |
| ‹로 목록에 돌아갈 때 | 목록에서 [고치기]를 누른 그 행의 [고치기]. 행이 없어졌으면 목록 제목 `#pl-title` |
| 목록을 열 때 | 목록 제목 `#pl-title` |
| 패널을 닫을 때(×, Esc) · 책상이나 보고서에서 연 패널 | **연 요소**(책상). 연 요소가 없어졌으면(보고서 "권한"은 보고서와 함께 사라짐) 그 대상의 책상(화면에 있으면) → HUD "권한 정책" 버튼 |
| 패널을 닫을 때(×, Esc) · 목록의 [고치기]·[대상 추가]로 연 패널 | **언제나 HUD "권한 정책" 버튼**(그 대상의 책상이 화면에 있어도). ‹는 목록으로 돌아갑니다 |
| 목록을 닫을 때 | HUD "권한 정책" 버튼 |
| 저장 성공·실패 | [저장]에 그대로(실패 문구는 `role="alert"`로 읽힘) |

- 서랍은 비모달입니다. 포커스를 가두지 않고, 바깥을 눌러도 닫지 않습니다.
- **Esc 순서:** 말풍선 → 목록의 지우기 확인(§4.3) → 대상 추가 칸(접힘, 포커스는 `[+ 대상 추가]`) → 서랍.
- Tab 순서(패널): ‹ → × → (화면에 없는 이름 안내에는 컨트롤 없음) → "그 밖의 모든" 정책 보기 → 템플릿 세 개 → 일곱 줄(각 줄은 고른 라디오 하나만 Tab에 걸리고, 줄 안에서는 ←/→·↑/↓, 브라우저 기본) → 서브에이전트 버튼들 → [저장].
- Tab 순서(목록): × → 행마다 [고치기] → [지우기] → [+ 대상 추가] → (칸이 펼쳐졌으면 종류 → 이름 → 취소 → 열기).

### 7.3 live region

새 `role="status"`를 만들지 않습니다. App의 하나뿐인 status에 `announce`로 넣습니다(§8.6). 실패 문구만 `role="alert"`입니다.

### 7.4 움직임 줄이기

새 애니메이션은 서랍의 `slide-in`(기존) 하나뿐입니다. 전역 규칙(`animation: none !important; transition: none !important`)으로 즉시 표시됩니다. 자물쇠·막힘 표시는 처음부터 움직이지 않습니다.

### 7.5 좁은 화면 (≤ 720px)

- 패널·목록은 보고서처럼 아래 시트: `width: 100vw; top: 8vh; border-left: 0; border-top: 4px solid var(--policy)`.
- **권한 칸 줄(폭 ≤ 480px):** 이름과 값이 한 줄에 들어가지 않으므로 두 줄 격자로 바꿉니다(행·열 모두 명시).

  | 선택자 | 값 |
  |---|---|
  | `.pr-row` | `grid-template-columns: repeat(3, minmax(0, 1fr)); grid-template-rows: auto auto; row-gap: 4px` |
  | `.pr-name` | `grid-column: 1 / 4; grid-row: 1` |
  | `.pr-opt--default` | `grid-column: 1; grid-row: 2` |
  | `.pr-opt--ask` | `grid-column: 2; grid-row: 2` |
  | `.pr-opt--deny` | `grid-column: 3; grid-row: 2` |

- **목록 행(폭 ≤ 480px):** 버튼을 아래 줄로 내립니다.

  | 선택자 | 값 |
  |---|---|
  | `.pl-row` | `grid-template-columns: minmax(0, 1fr); grid-template-rows: auto auto auto` |
  | `.pl-name` | `grid-column: 1; grid-row: 1` |
  | `.pl-sum` | `grid-column: 1; grid-row: 2` |
  | `.pl-act` | `grid-column: 1; grid-row: 3; justify-content: flex-end; margin-top: 6px` |
  | `.pl-err` | `grid-column: 1; grid-row: 4` |

- 저장 영역: 상태 줄이 두 줄로 꺾여도 [저장]은 오른쪽에 남습니다(`flex: none`).

## §8 문구표

`{…}`는 바뀌는 값입니다. 「스펙」은 스펙·Global Constraints에 글자가 정해진 문구라 qa 검토에서도 바꾸지 않습니다(바꾸려면 director Ruling).

### 8.1 이름

| 항목 | 문구 |
|---|---|
| 대상 화면 이름(B76) | `lead` → `리드` / `agent:{이름}` → `{이름}` / `sub:{종류}` → `서브에이전트({종류})` / `others` → `그 밖의 모든 팀원·서브에이전트` |
| 종류 칩 | `리드` · `팀원` · `서브에이전트` · `그 밖의 모든` |
| 묶음 화면 이름 「스펙」 | `명령 실행` · `파일 고치기` · `웹 접근` · `팀원·서브에이전트 만들기` · `외부 도구(MCP)` · `그 밖의 도구` · `모든 도구` |
| 값 「스펙」 | `기본` · `항상 질문` · `금지` |
| 템플릿 「스펙」 | `읽기 전용` · `명령은 물어보고` · `제한 없음` |

### 8.2 에이전트 패널

| 위치 | 문구 |
|---|---|
| 적용 범위 줄 · 팀원, 서브에이전트 「스펙」 | `이 이름의 정책은 다른 세션의 같은 이름에도 적용됩니다` |
| 적용 범위 줄 · 리드 | `리드의 정책은 모든 세션의 리드에 적용됩니다` |
| 적용 범위 줄 · 그 밖의 모든 | `따로 정하지 않은 모든 팀원·서브에이전트에 적용됩니다. 리드에는 적용되지 않습니다` |
| ‹ aria-label | 리드로 → `리드 권한으로 돌아가기` / 목록으로 → `정책 목록으로 돌아가기` / 원래 대상으로 → `{대상 화면 이름} 권한으로 돌아가기` |
| × aria-label | `닫기` |
| 화면에 없는 이름 | `지금 화면에 이 이름이 없습니다. 정해 두면 이 이름이 나타날 때부터 적용됩니다.` |
| 횟수 「스펙」 | `켠 뒤로 금지 {n}번 · 질문 {n}번` |
| 횟수 0 | `켠 뒤로 막거나 물은 적 없음` |
| 횟수 보조 | `대시보드를 다시 켜면 0부터 셉니다` |
| others 따름 「스펙」 | `정한 것이 없어 "그 밖의 모든"을 따릅니다` |
| others 링크 | `"그 밖의 모든" 정책 보기` |
| others 경고 | `여기서 하나라도 정해 저장하면 이 이름은 "그 밖의 모든"을 따르지 않습니다. 기본으로 둔 도구는 원래 규칙대로 합니다.` |
