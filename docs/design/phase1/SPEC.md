# Phase 1 디자인 명세: 야근 빌딩

- 시안: `index.html`(같은 폴더). 브라우저로 바로 엽니다. 위쪽 점선 상자 "시안 조작"으로 모든 상태를 바꿔 볼 수 있습니다. 이 상자는 제품에 넣지 않습니다.
- 대상: developer. 이 문서의 값, 픽셀 맵, 문구는 그대로 옮겨 씁니다. 시안의 `<style>`과 `<script>`에도 같은 값이 있으니 헷갈리면 시안 코드를 기준으로 삼습니다.
- 시안에서 빠진 동작: 자동으로 닫히기(1.5초/5초), "전체 보기" 펼치기, 스크린 리더 시간 알림, 접힘 상태 기억은 시안에 넣지 않았습니다. 이 문서가 기준입니다.
- 범위: T1.4 빌딩 레이아웃, T1.5 말풍선, T1.6 손들기와 노란 ?. 결정 보고서 패널은 Phase 2(T2.2) 구현분이지만 모양은 지금 정합니다. 층 컨트롤도 Phase 1에서는 자리만 두고 Phase 4에서 동작하게 합니다.

## 1. 가정 (모호한 점을 designer가 정한 것)

| # | 가정 | 이유 |

| A1 | 층 번호는 **가장 오래된 세션이 1F**이고, 새 세션일수록 위층입니다. 맨 위에는 항상 "빈 층"이 하나 있습니다. 층을 삭제하거나 세션이 끝나 목록에서 빠지면 번호를 다시 매깁니다(Phase 1 확정). 그래서 오래된 세션이 빠지면 그 위층 번호가 하나씩 내려갑니다. 화면 위치는 바뀌지 않습니다. 새 층은 위에 쌓이고 빠진 층 아래의 내용만 올라오기 때문입니다. 층 번호를 고정할지는 층 삭제가 생기는 Phase 4에서 다시 정합니다. | 건물이 위로 자라는 모습을 표현했습니다. 번호보다 층 이름이 식별자 역할을 합니다. **확정(13장 Q2).** |

- `Member.state`에 `"decision"`을 추가합니다. 우선순위는 `decision > working > mail > idle > offline`입니다.
- `Member.activity`: `{ tool, target, startedAt }`(T1.3). `Member.decision?`: `{ kind, id, deadline }`.

### 3.1 폰트 로드 (확정)

- **npm 패키지 `galmuri`를 의존성에 추가**하고 번들에 포함합니다. 시안은 jsdelivr CDN을 쓰지만, **제품은 CDN을 쓰지 않습니다.** 로컬 대시보드는 오프라인에서도 같은 모습이어야 하고, 외부 요청도 없어야 합니다.
- `web/styles.css` 맨 위에 `@import "galmuri/dist/galmuri.css";`를 넣습니다. Vite가 node_modules의 CSS와 woff2를 번들 자산으로 복사합니다. 브라우저는 실제로 쓰는 Galmuri11과 Galmuri14만 내려받습니다. 패키지 CSS에 이미 `font-display: swap`이 들어 있습니다.
- **로드에 실패하면** `--font-pixel`의 나머지 목록(`ui-monospace, "SF Mono", Menlo, monospace`), 즉 v1과 같은 monospace로 표시됩니다. Galmuri14를 쓰는 곳(층 번호, 간판, 팻말)도 `font-family: "Galmuri14", var(--font-pixel)`로 적어 같은 대체 경로를 탑니다.
- 폰트가 바뀌어도 레이아웃이 깨지지 않게 합니다. 층 이름은 이미 말줄임 처리가 되어 있고, 칩과 버튼에는 고정 폭을 주지 않습니다.
- 라이선스는 SIL OFL 1.1입니다. 배포할 때 저작권 표시를 `THIRD_PARTY_NOTICES`(또는 README의 라이선스 절)에 한 줄 적습니다.

### 3.2 간격과 글자

- 간격은 4px 단위로 맞춥니다(4, 6, 8, 10, 12, 16). 모서리는 둥글리지 않습니다(radius 0). 그림자는 흐림 없이 `0 2px 0 var(--slab)`처럼 아래로만 떨어지는 도트 그림자를 씁니다.
- 글자 크기: 10(보조), 11(라벨·칩), 12(기본), 14(층 이름, 보고서 본문), 16(층 번호, Galmuri14), 17(보고서 제목, 굵게), 18(간판, Galmuri14)을 씁니다.

### 4.2 캐릭터 (8×10)

`BODY_A`와 `BODY_B`는 v1 그대로 씁니다. **`BODY_UP`(손들기)을 새로 추가합니다.** 오른팔(8번째 열)을 머리 옆으로 곧게 올린 모습입니다. 0–1행이 손, 2–6행이 소매이고, 7–8행의 오른팔 자리는 비웁니다.

```ts
const BODY_UP = [
  "..hhhh.s",
  ".hhhhhhs",
  ".hsssssc",
  ".sessesc",
  ".ssssssc",
  "..ssss.c",
  ".ccccccc",
  "ccccccc.",
  "cc.cc.c.",
  ".pp..pp.",
];
```

역할별 덮어쓰기(`characterRows(role, "up")`):
- reviewer: `rows[3] = ".geggegc"`
- lead: `rows[6] = ".ccttccc"`, `rows[7] = "cccttcc."`

> 8칸 폭에서는 팔을 흔드는 두 번째 프레임을 만들 수 없습니다. 팔을 내리면 손이 얼굴 피부와 붙어 버립니다. 그래서 **같은 맵을 1도트 위로 옮긴 "콩콩 뛰기"**를 두 번째 프레임으로 씁니다(6장).

## 7. "지금 하는 일" 말풍선

### 7.1 모양

- `position: fixed`인 말풍선 하나를 모든 책상이 함께 씁니다. 최대 폭 340px, 배경 `--panel`, 2px `--cyan` 테두리, 여백 6px 10px 6px 8px, `box-shadow: 0 4px 0 var(--slab)`, `pointer-events:none`입니다.
- 1줄: 아이콘 14px + 간격 6px + 문장 12px(한 줄, 넘치면 CSS 말줄임)입니다.
- 2줄(보조, 10px `--muted`, 왼쪽 여백 20px): `{모델} · 토큰 {n} · {경과}`입니다. 경과 시간은 60초 미만이면 `N초째`, 60분 미만이면 `N분째`, 그 이상이면 `N시간째`로 쓰고 모두 내림합니다(59초 → 59초째, 125초 → 2분째, 7200초 → 2시간째). 결정 대기면 노란 글자로 "누르면 결정 보고서가 열립니다"(Phase 1에서는 "결정 보고서는 다음 버전에서 열립니다", 6장)를 쓰고, 종료면 비웁니다.
- **서브에이전트가 한 일**: 일반 서브에이전트(Task/Agent로 띄운 것)의 도구 호출은 리드 캐릭터에 합칩니다. 이때 보조 줄 맨 앞에 `서브에이전트 · `를 붙이고, `agent_type`을 알면 `서브에이전트({agent_type}) · `로 씁니다. 예: `서브에이전트(Explore) · sonnet · 토큰 12k · 4초째`. 첫 줄 문장, 아이콘, 테두리는 바꾸지 않습니다. 서브에이전트 여러 개가 동시에 일하면 가장 최근에 도구를 시작한 것 하나만 보여줍니다.
- 꼬리: 8×8 정사각형을 45° 돌려 아래 가운데에 둡니다. 테두리 색은 말풍선과 같습니다.
- 결정 대기일 때는 테두리와 꼬리를 `--yellow`로 바꿉니다.

### 7.3 자르기

- 「」 안의 값은 **최대 28자**입니다(`Intl.Segmenter`가 있으면 글자 단위, 없으면 코드포인트).
  - 파일 이름: 경로에서 마지막 부분만 쓰고, 넘치면 **가운데를 "…"로 줄여** 확장자를 살립니다. 예: `「2026-09-28-cla…ice-design.md」`
  - 나머지: **끝을 줄입니다.** 예: `「Run the full vitest suite w…」`
- 문장 전체가 340px를 넘으면 CSS `text-overflow: ellipsis`로 한 번 더 자릅니다.
- 줄바꿈과 연속 공백은 공백 하나로 바꿉니다.
- 줄이기 전의 전체 문장은 필요하면 결정 보고서의 "지금까지의 흐름"에서 볼 수 있습니다. 말풍선에 title은 달지 않습니다(툴팁이 겹칩니다).
- 아이콘 강조색(`a`): 결정 대기면 선과 강조 모두 `--yellow`, 그 밖에는 선 `--cyan`에 강조 `--green`입니다.

### 7.4 위치

1. 기준점은 캐릭터의 가로 중심(책상 왼쪽 + 36px)과 머리 위(책상 위쪽 + 28px)입니다.
2. `left = clamp(8, cx − w/2, innerWidth − w − 8)`로 화면 가장자리에서 8px 안쪽을 유지합니다.
3. `top = 머리 위 − h − 10`으로 잡습니다. 이 값이 sticky HUD 아래쪽 + 4px보다 작으면 **캐릭터 아래(책상 위쪽 + 86px)로 뒤집고** 꼬리를 위로 향하게 합니다(`.below`).
4. 꼬리의 x는 `clamp(12, cx − left, w − 12)`입니다. 말풍선이 밀려나도 꼬리는 캐릭터를 가리킵니다.

### 7.5 타이밍과 입력

| 입력 | 동작 |
|---|---|
| 마우스 진입 | 150ms 뒤 표시. 다른 캐릭터로 옮기면 바로 바뀜 |
| 마우스 이탈 | 100ms 뒤 숨김 |
| 키보드 포커스 | 즉시 표시. 포커스를 잃으면 숨김 |
| Esc | 숨김 |
| 스크롤 | 숨김 |
| 터치 | 첫 탭에 표시. 결정 대기 캐릭터는 두 번째 탭에 보고서 열기 |
| 표시 중 내용 변경(SSE) | 문장만 바꿈. 위치는 다시 계산 |

말풍선은 한 번에 하나만 뜹니다. 등장 애니메이션은 없습니다.

## 11. 접근성

- **포커스 링**: 전역 `:focus-visible { outline: 2px solid var(--focus); outline-offset: 2px }`를 씁니다.
- **책상**
  - 평소에는 `<div tabindex="0" role="img" aria-label="{이름}, {상태}">`입니다. 포커스하면 말풍선이 뜨고 `aria-describedby="say"`로 연결됩니다.
  - 결정 대기면 `<button aria-haspopup="dialog" aria-label="{이름}, 결정 필요. 결정 보고서 열기">`입니다. Enter와 Space로 엽니다.
  - Tab 순서: 층 머리 컨트롤 → 방의 책상(왼쪽에서 오른쪽) → 다음 층.
- **말풍선**: `role="tooltip"`, `id="say"`. 상태 문장은 SVG가 아니라 텍스트로 넣습니다.
- **층**: `<section aria-labelledby="{층 이름 h2}">`. 접기 버튼은 `aria-expanded`와 `aria-controls`를 가집니다.
- **스위치**: `role="switch" aria-checked`. Space로 전환합니다.
- **바**: v1 HeartBar처럼 `role="meter"`, `aria-label="{라벨} 남은 양"`, `aria-valuenow`를 씁니다.
- **HUD 결정 칩**: `aria-label="결정 대기 {N}건, 다음 요청 열기"`. 새 결정이 생기면 숨긴 `role="status"` 영역에 "{층} {이름}이(가) 결정을 기다립니다"를 한 번 알립니다.
- **결정 보고서**
  - `role="dialog" aria-modal="false" aria-labelledby="rp-title" aria-describedby="rp-what"`입니다.
  - 열리면 제목(`tabindex="-1"`)에 포커스를 줍니다. Esc나 [×]로 닫으면 **연 캐릭터에 포커스를 되돌립니다.** 캐릭터가 사라졌으면 HUD 결정 칩으로, 그것도 없으면 그 층의 접기 버튼으로 보냅니다.
  - 상태 배너는 `role="status"`, 보내기 실패만 `role="alert"`입니다.
  - 선택지는 `<fieldset>`과 숨긴 `<legend>선택지</legend>`, 라디오는 화살표 키로 이동합니다.
  - 남은 시간 막대는 `role="timer"`, 알림은 8.4의 규칙을 따릅니다.
- **대화상자**: 네이티브 `<dialog>.showModal()`을 쓰고 Esc는 취소로 처리합니다.
- **대비**: 모든 글자 조합은 `--panel` 또는 `--wall` 위에서 4.5:1 이상입니다(`--muted` #9d97c7 on #0e0d18 약 7:1). 노란 바탕 위의 글자는 `--wall`을 씁니다.
- **색에만 의존하지 않기**: LED 옆에는 항상 칩 글자나 aria-label로 상태를 적습니다.
