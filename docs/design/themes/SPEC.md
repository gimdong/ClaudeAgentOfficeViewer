# 테마(스킨) — 목업과 테마 계약 초안

근거: 배정 #654(사용자 목적: "디자인을 스킨처럼 바꿔 끼우는 다른 테마로도 배포"). Phase 6c 디자인 개편의 목적입니다. **구현하지 않은 목업·초안**이며 확정되면 team-lead가 Phase 6c 스펙·계획을 씁니다. 글자는 모두 「안」.

## §1 오피스 테마 · 밝은 낮 (목업 ①)

`renders/theme-office-day-900.png`, `theme-office-day-360.png` · 밤 변형 `renders/theme-office-night-900.png`

한 장에 건물 전체: 하늘(구름·해)과 스카이라인 두 겹, **1층 로비**(관리 데스크와 경비, 로비 표지, 유리 입구, 지나가는 사람), 인도와 **도로·차**, **사무 층 둘**(밝은 벽, 줄무늬 카펫, 창밖 하늘, 형광등, 책상·모니터·앉은 팀원, 화분), **카페 층**(카운터·커피 머신·테이블, 쉬는 팀원), **옥상**(난간·화단·물탱크, 쉬는 팀원 후보 자리), 왼쪽 **엘리베이터 칸**(지금 3F에 서 있음 — HUD 엘리베이터와 연결).

- 밝은 낮이 기본입니다(사용자: 지금의 어두운 배경·책상이 거슬림). **밤**은 같은 장면의 팔레트만 바꾼 변형으로, 시스템 다크(`prefers-color-scheme: dark`)일 때나 사용자가 고를 때 씁니다.
- 층 이름표(`3F 팀 fake-shop` 등)·버튼·말풍선은 **그림이 아니라 DOM 글자**(공통 UI)입니다. 낮에는 흰 바탕 + 진한 글자, 밤에는 진한 바탕 + 밝은 글자 — 둘 다 대비 4.5:1 이상(§6).
- 그림 속 사람은 건물 장면용 작은 스프라이트(10×15칸)입니다. 책상을 누르거나 층을 펼치면 phase6b·beta15 §8의 큰 스프라이트(26×30칸)로 봅니다.

| 우주선 | 별 하늘과 행성, 금속 패널 벽, 둥근 창 대신 어두운 관측창, 옥상 안테나 접시, 도로 대신 격납고 활주로와 셔틀, 로비는 로봇 안내원 |
| 사이버펑크 | 비 오는 밤 도시, 보라 외벽, 네온 간판(옥상), 네온 선 바닥, 공중 차, 로비는 드론 안내원 |

- 층 이름표·버튼·HUD 숫자는 세 테마 모두 같습니다(공통 UI).

## §4 테마 계약 (목업 ④, 초안)

테마 하나 = **팔레트 + 스프라이트 시트 + 장면 칸 + 이름**을 담은 폴더 한 개. 화면 코드는 테마를 몰라도 되고, 칸 이름으로만 그림을 부릅니다.

### 4.1 폴더와 목록 파일

```
themes/<id>/
  theme.json        이름·팔레트·칸 → 시트 자리 표(아래)
  sprites.png       캐릭터·소품 시트(팔레트 PNG, 1배율)
  scene.png         장면 칸 시트(배경·바닥·책상·의자·모니터·건물 바깥)
  LICENSE / CREDITS 그림 출처(공개 저장소 — 자기 그림이거나 허락 받은 그림만)
```

`theme.json`(초안):

```json
{
  "id": "office",
  "name": "오피스",
  "variants": ["day", "night"],
  "tile": 4,
  "palette": { "day": { "sky": "#8fcfff", "wall": "#f5f1e8", "…": "…" }, "night": { "…": "…" } },
  "sheets": { "sprites": "sprites.png", "scene": "scene.png" },
  "cells": { "character.walk.side": { "sheet": "sprites", "x": 0, "y": 0, "w": 26, "h": 44, "frames": 4 }, "…": "…" }
}
```

- 시트 좌표·크기는 **칸(1배율 도트)** 단위. 화면은 정수 배율(×2·×3·×4)로만 키우고 `image-rendering: pixelated`.
- 프레임은 시트 안에서 **가로로 나란히**(같은 `y`, `x + w × i`). CSS `background-position` + `steps(frames)`로 돌립니다.

### 4.2 테마가 채워야 할 칸

| 묶음 | 칸 이름 | 크기(칸) | 프레임 |
|---|---|---|---|
| 캐릭터(사람마다 변형) | `character.{walk.side, walk.front?, stand, sit, idle}` | 26×44 | 4 / 2 / 1 / 1 / 2 |
| 캐릭터 표정(얼굴 덮개) | `face.{work, think, rest, hand}` | 26×16 | 1 |
| 캐릭터 변형 | `variant.hair.{1..n}`, `variant.outfit.{1..n}`, `variant.glasses` | 26×44 겹침 | 1 |
| 오라(일하는 중) | `aura.{1..4}` | 44×52 | 2 |
| 책상 세트 | `desk`, `chair`, `monitor.{work, idle, decision, off}`, `keyboard`, `mug`, `plant`, `memo` | 64×44 안 | 모니터 work 4 |
| 층 실내 | `room.wall`, `room.ceiling`, `room.floor`, `room.window`, `room.light` | 반복 타일 8×8 또는 띠 | 1 |
| 쉬는 곳 | `rest.{cafe, rooftop, pantry}`(테마가 고른 하나 이상) | 64×44 | 1 |
| 건물 바깥 | `outside.sky.{day, night}`, `outside.skyline`, `outside.ground`, `outside.road`, `outside.vehicle.{1..n}`, `outside.passerby` | 띠·스프라이트 | 탈것 1, 행인 4 |
| 로비 | `lobby.desk`, `lobby.guard`, `lobby.entrance`, `lobby.sign` | — | 경비 대기 2 |
| 엘리베이터 | `elevator.shaft`(세로 타일), `elevator.car`, `elevator.door.{open, closed}` | 16×30 | 문 2 |
| 표지 | `mark.hand`(손들기 "!" 풍선), `mark.folder`, `mark.sign.offduty` | — | 1 |

- 없는 칸은 **기본 테마(오피스)의 칸으로 대신**합니다(테마가 일부만 바꿔도 깨지지 않게).
- 칸마다 **색만 바꾸는 변형**은 팔레트 토큰으로(§4.3), **모양이 다른 변형**만 시트에 따로 그립니다.

### 4.3 팔레트 토큰

테마가 정하는 것(그림·장식): `sky`, `skyline`, `facade`, `wall`, `floor`, `desk`, `window`, `light`, `road`, `accent`, `outline`.

**공통 UI가 정하는 것(테마가 못 바꿈):** 글자색 `--ink`/`--wall`, 버튼·칩 색(`--green` 승인, `--pink` 위험·수정 요청, `--yellow` 결정, `--cyan` 포커스·답을 기다립니다, `--red` 오류, `--violet` 권한 정책), 포커스 링, 서랍·창 배경. 테마는 이 색을 **덮어쓰지 않고**, 대신 공통 UI 아래에 깔리는 배경만 바꿉니다.

### 4.4 공통 UI와 테마의 경계

| 공통(모든 테마 같음) | 테마(바뀜) |
|---|---|
| HUD 숫자·막대·칩, 층 이름표, 말풍선·결정 보고서·서류철·패널·창, 버튼·글자·aria, 키보드 순서, 문구 | 하늘·건물 바깥·층 실내·책상 세트·캐릭터 생김새·동작 그림·탈것·로비·엘리베이터 모양·장식 |
| 상태의 뜻(손들기 = 결정, 하늘 = 답을 기다립니다, 퇴근 팻말 …) | 그 상태를 그리는 그림(예: 판타지의 "!"는 두루마리 모양이어도 됨 — 단 자리·크기·aria는 공통) |

- 데이터와 이어지는 그림은 **상태와 같은 뜻**이어야 합니다(쉬는 팀원 → 쉬는 곳, 엘리베이터 → 지금 보는 층). 나머지(차·행인·구름)는 장식이고 데이터와 무관.
- 글자는 시트에 넣지 않습니다(번역·접근성·글꼴은 공통 UI).

### 4.5 대비 규칙

- 공통 UI 글자는 그 바로 아래 배경과 **WCAG AA 4.5:1**(큰 글자 3:1) 이상. 테마가 밝으면 이름표·말풍선은 흰 바탕 + 진한 글자, 어두우면 진한 바탕 + 밝은 글자(그림 ① 낮·밤).
- 테마 검사: `theme.json` 팔레트의 `wall`·`sky` 위에 공통 이름표를 얹어 대비를 재는 테스트를 둡니다(확정 뒤).
- 움직임 줄이기·고대비 모드에서는 장식 애니메이션을 끄고(차·행인·구름 정지) 상태 표시만 남깁니다.

### 4.6 성능 예산(초안)

| 항목 | 예산 |
|---|---|
| 테마 하나의 시트 합계 | 압축 **200KB 이하**(팔레트 PNG, 1배율) |
| 한 화면 애니메이션 | 보이는 층만 돌림(`content-visibility` 또는 IntersectionObserver), 화면 밖 층·접힌 층 정지 |
| 그리기 | 인라인 SVG 대신 시트 + CSS 배경(책상 세트 하나 = 요소 몇 개). beta15 §8.1의 인라인 SVG 기준(책상 하나 rect 418개)을 넘지 않음 |
| 건물 장면 | 바깥 장식(차·행인)은 한 번에 최대 4개, 0.5초 이하 steps |
| 팀원 30명 | 60fps에서 프레임 처리 4ms 이하가 목표(구현 때 측정) |

### 4.7 라이선스

- 테마 그림은 저장소 라이선스(MIT)와 같이 배포할 수 있는 것만. 다른 작품의 이름·로고·캐릭터·지도·건물 모양을 쓰지 않습니다. 판타지는 "돌 성벽·탑·깃발·횃불" 같은 일반 요소로 새로 그립니다.
- `CREDITS`에 그린 사람·도구를 적습니다.

## §5 엘리베이터·재미 공간(초안)

- **엘리베이터:** 지금 HUD 엘리베이터(층 바로가기)를 누르면 건물 장면의 엘리베이터 칸이 그 층으로 칸 단위로 움직이고(0.12초/층, steps), 문 열림 2프레임 뒤 그 층으로 스크롤. 움직임 줄이기면 바로 그 층.
- **카페·옥상·탕비실:** 쉬는 팀원(오래 쉼·퇴근 전 쉼)이 가는 곳. 테마가 하나 이상 고릅니다(`rest.*`). 어느 곳으로 갈지는 화면이 고르고 서버 데이터는 쓰지 않습니다(상태만 씀).
- **로비 경비·행인·차:** 장식. 데이터와 무관.
