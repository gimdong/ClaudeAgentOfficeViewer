# v2 Phase 7 Implementation Plan — 테마 구조와 오피스 테마

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 화면을 바꿔 끼울 수 있는 테마 구조로 만들고, 첫 테마인 오피스(낮·밤, 건물 바깥, 걷기·카페, 하위 팀, 1인칭 보고서)를 완성한다.

**Architecture:** 테마는 `web/themes/<id>/`의 `theme.json` + `tokens.css`(`--th-*`만) + 생성기로 만든 PNG 시트이고, 빌드 때 `import`로 묶는다. 서버는 세 가지만 새로 준다(변형 설정, 노력 정도, 하위 팀). 걷기·탕비실·엘리베이터 연출은 화면이 스냅샷 상태로 정하는 순수 함수(계획기)와 CSS `steps()` 애니메이션으로 한다.

**Tech Stack:** Node, Express 5, React, Vitest. 새 의존성 없음.

**Spec:** `docs/superpowers/specs/2026-10-25-v2-phase7-design.md` · **디자인 계약:** `docs/design/phase7/SPEC.md`(`design/p7-lead`, 기준 261b1cf — 구현 시작 때 그 브랜치 끝으로 다시 확인. 둘이 다르면 계약을 따르고 스펙을 고친다)

**배포 묶음(사용자 결정 2026-10-26: 7a·7b·7c로 나눠 각각 beta):**
- **7a** Task 1–6: 테마 구조·낮밤·층 안·캐릭터·탕비실 → beta.18

## Global Constraints
- 새 의존성 없음. 생성기는 Node 표준만(`zlib` 등). Playwright는 job tmp에만, 저장소에 넣지 않는다.
- `~/.claude`에 쓰지 않는다. 새 상태는 `<PREFIX>/building.json`(variant)과 `<PREFIX>/groups.json`(0600, 임시 파일 뒤 rename)만.
- 테마가 바꾸는 것은 그림 시트·`--th-*`·`words` 셋뿐. 공통 UI 토큰 `--ink --wall --panel --muted --green --pink --yellow --yellow-ink --cyan --red --violet --focus`는 테마 `tokens.css`에 나오면 빌드 검사 실패.
- 글자는 언제나 DOM이고 불투명 판 위. 글/판 4.5:1, 비텍스트 3:1. 포커스 링 `outline: 2px solid var(--focus); box-shadow: 0 0 0 6px var(--ink)`.
- 장면 그림 합계 테마·변형당 64KB 이하. 반투명 빛 금지. 이동은 `transform`만, `image-rendering: pixelated`, 정수 배율. 런타임 `filter`·`hue-rotate` 금지.
- 장식(행인·차·손님·경비)은 `aria-hidden`, 누를 수 없음. 행인 2 + 차 2 이하.
- 움직임 줄이기(`prefers-reduced-motion`): 걷기·탑승 없이 목적지 정지 그림, 깜빡임·밝기 변화 없음.
- 지식재산권: 분위기만 참고. 이름·로고·그림을 베끼지 않는다. 실제 사용자 이름·경로를 그림·픽스처에 넣지 않는다.
- 사용자 4317·설치본·`~/.claude` 접근 금지, 시험 포트 4320+. sha1 기준 `f751ed59f5f6` 전후 비교. 커밋 전 `git diff --cached --stat`, 경로 지정 커밋.
- 숫자 상수는 이 문서와 계약 값 그대로: 쉼 걷기 30초, `longIdle` 1시간, 동시 걷기 2명, 엘리베이터 1명, 층당 0.12초·최대 0.6초, 문 100ms×3.
