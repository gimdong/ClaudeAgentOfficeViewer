# Claude Agent Office Viewer v2 Phase 1 Implementation Plan — 이벤트 브리지와 빌딩 UI

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Claude Code의 hook 이벤트를 플러그인으로 받아, 에이전트가 지금 하는 일과 결정 대기 상태를 빌딩(층) 화면에 보여준다. 조작 기능은 없다.

**Architecture:**
- **플러그인:** 저장소 자체가 마켓플레이스다. `claude-office` 플러그인의 `hooks.json`이 13개 이벤트를 `http://127.0.0.1:4317/hooks/event`로 보낸다(`type: "http"`, timeout 5).
- **서버:** `POST /hooks/event`가 요청을 검증하고 즉시 200을 돌려준다. `EventStore`(메모리, 에이전트마다 20개)가 요약된 이벤트를 보관하고, 순수 함수 `deriveAgent`가 에이전트별 `activity`와 `decision`을 계산한다. `SnapshotBuilder`는 v1 파일 수집기 결과에 이 값을 덧입힌다. 이벤트가 오면 `SnapshotHub.poke()`가 200ms 안에 스냅샷을 다시 만든다.
- **화면:** v1의 `OfficeGrid`/`OfficeTile`을 `Building`/`Floor`로 바꾼다. 층 하나가 세션 하나이고, 1F가 가장 오래된 세션이다. 책상에 손들기와 노란 ?, 화면에 하나뿐인 "지금 하는 일" 말풍선을 더한다.

**Tech Stack:** Node 24 (ESM), TypeScript, Express 5, React 19, Vite, Vitest, jsdom, @testing-library/react, `galmuri`(도트 한글 폰트, npm)

**Spec:** `docs/superpowers/specs/2026-10-01-v2-phase1-design.md`
**디자인 명세(UI 값의 기준):** `docs/design/phase1/SPEC.md`, 시안 `docs/design/phase1/index.html`
**v1 계획서(형식과 기존 코드의 근거):** `docs/superpowers/plans/2026-09-28-claude-agent-office-viewer.md`

## Global Constraints

- v1의 제약은 그대로다: Node ≥ 24, `127.0.0.1`에만 바인딩, Host 검사, 서버는 claude home 아래에 **아무것도 쓰지 않는다**, UI 문구는 한국어, 이미지 파일을 쓰지 않는다(도트는 모두 코드).
- hook URL은 `http://127.0.0.1:4317/hooks/event` 하나다. 모든 hook은 `"type": "http"`, `"timeout": 5`. 도구 이벤트(`PreToolUse`, `PostToolUse`, `PostToolUseFailure`, `PermissionRequest`, `PermissionDenied`)는 `"matcher": "*"`.
- 대상 이벤트 13개: `SessionStart`, `SessionEnd`, `UserPromptSubmit`, `PreToolUse`, `PostToolUse`, `PostToolUseFailure`, `PermissionRequest`, `PermissionDenied`, `Notification`, `SubagentStart`, `SubagentStop`, `TeammateIdle`, `Stop`.
- `POST /hooks/event`: `Content-Type`이 JSON이 아니면 **415**, `Origin` 헤더가 있으면 **403**, Host가 로컬이 아니면 **403**, 본문이 1MB를 넘으면 **413**, `hook_event_name`·`session_id`가 문자열이 아니면 **400**. 그 밖에는 처리 중 예외가 나도 **200과 빈 본문**. 어떤 결정도 돌려주지 않는다.
- `EventStore`: 에이전트 키 `(session_id, 에이전트 이름)`마다 최근 **20개**. `tool_input`은 요약 필드(`command`, `description`, `file_path`, `pattern`, `query`, `url`의 도메인, `to`, `activeForm`, 질문 텍스트)만, 각 **200자**까지. 메모리에만 둔다. 세션이 끝나고(또는 마지막 이벤트 뒤) **24시간**이 지나면 버린다.
- 에이전트 이름: `agent_id`가 없으면 `"team-lead"`. `TeammateIdle`이면 `teammate_name`. `agent_id`가 `a<16진수>`면 일반 서브에이전트로 보고 **리드에 합친다**(`sub: true`). 그 밖에는 `agent_type`(팀원 이름). `agent_type`이 빈 문자열인 `SubagentStart`/`SubagentStop`은 무시한다.
- 진행 중인 도구는 **10분**, 결정 대기는 **30분**이 지나면 뺀다.
- `MemberState` 우선순위: `decision > working > mail > idle > offline`. 세션이 죽었으면 `offline`이 먼저다.
- 층 번호: **시작 시각이 가장 오래된 세션이 1F**. 화면은 위가 최신 층, 맨 위는 항상 빈 층.
- 개발·실험 서버는 **4318**을 쓴다. 사용자의 v1 뷰어가 쓰는 **4317은 쓰지도 끄지도 않는다.**
- 팀은 `~/.claude` 설정을 수정하지 않는다. 플러그인은 실험 세션에서 `claude --plugin-dir <폴더>`로만 로드한다. 자격 증명 파일은 읽지도 옮기지도 않는다. 테스트 fixture에는 **가짜 값만** 쓴다.
- UI의 크기·색·픽셀 맵·문구는 `docs/design/phase1/SPEC.md`의 절 번호를 따른다. 시안 코드(`index.html`)는 **값(색, 크기, 픽셀 맵, 타이밍)에만** 기준이 된다. SPEC.md가 스스로 우선한다고 적은 곳(7.2 "우선순위(확정)"), 시안 이후 커밋 `0e625f0`·`c1f8ee4`의 결정, 시안에 없다고 밝힌 동작은 **SPEC.md**가 이긴다(team-lead 정정 2026-10-01). 이 계획서의 스펙과 디자인 명세가 다르면 **디자인 명세**가 이긴다. 기능 범위만 스펙이 정한다.
- Phase 1의 층 컨트롤과 "새 세션 시작"은 모두 `aria-disabled="true"`, 투명도 0.4, title `"아직 사용할 수 없습니다"`.
- 폰트는 npm `galmuri`를 번들한다. **CDN을 쓰지 않는다.**
- v1 테스트 158개는 모두 통과해야 한다. **예외:** 디자인이 없앤 대상을 검사하는 v1 테스트(캐릭터 팝오버 1개, `OfficeTile` 3개, `OfficeGrid` 2개)는 같은 뜻의 `Floor`/`Building` 테스트로 **바꿔 쓴다.** 전체 테스트 수는 줄지 않는다(Ruling P1, 아래 "계획서 판정").

## Review Focus

1. **hook 이벤트 폭주(병렬 도구 호출, 초당 수십 건):** 화면 갱신은 초당 5번을 넘지 않고 메모리는 에이전트당 20개로 묶여야 한다. → Task 4 테스트 `poke를 50번 불러도 한 번만 다시 만든다`
2. **이모지·결합 문자·줄바꿈이 섞인 명령과 설명:** 28자 자르기가 글자를 깨뜨리지 않고(서로게이트·ZWJ 시퀀스 유지), 줄바꿈은 공백 하나가 되어야 한다. → Task 9 테스트 `이모지와 결합 문자를 한 글자로 센다`
3. **이벤트 누락과 순서 어긋남(Post가 Pre보다 먼저, 서버 재시작 중 도구 실행, SessionEnd 없이 종료):** 캐릭터가 영원히 "작업 중"이나 손든 채로 남지 않아야 한다. → Task 5 테스트 `짝 없는 Post는 무시`, `10분이 지난 도구는 뺀다`, `30분이 지난 결정은 내린다`
4. **localStorage가 막힌 브라우저(Safari 개인 정보 보호 모드):** 접기 상태를 기억하지 못해도 빌딩은 그려져야 한다. → Task 11 테스트 `localStorage가 예외를 던져도 층을 그린다`
5. **아주 큰 `tool_input`(1MB 안쪽의 Write 내용)과 세션 파일 없는 세션의 이벤트:** 저장된 요약은 필드마다 200자 이하이고 원문은 남지 않으며, 세션 파일이 없는 세션은 층을 만들지 않아야 한다. → Task 3 테스트 `큰 Write 입력도 요약만 남는다`, Task 6 테스트 `세션 파일이 없는 이벤트는 층을 만들지 않는다`

## 계획서 판정 (계획을 쓰며 정한 것)

- **Ruling P1:** 스펙 13장 5번 "v1 테스트 158개 전부 통과"와 스펙 8장 "OfficeGrid/OfficeTile을 Building/Floor로 대체", 디자인 A4 "팝오버를 없앤다"가 충돌한다. 없어지는 대상을 검사하는 v1 테스트 6개는 같은 뜻의 새 테스트로 바꾸고, `app.test.tsx`의 `"office"` testid 검사는 `"floor"`로 바꾼다. 테스트 수는 줄이지 않는다.
- **Ruling P2:** 스펙 6장은 `TaskCreate`의 activeForm도 언급하지만, `TaskCreate`는 할 일을 대기(pending) 상태로 만들 뿐이다. 진행 중 표시는 `TodoWrite`의 `in_progress` 항목과 `status: "in_progress"`인 `TaskUpdate`에서만 얻고, `TaskUpdate`의 `completed`/`deleted`와 진행 중 항목이 없는 `TodoWrite`는 표시를 지운다.
- **Ruling P3:** 스펙 6장의 결정 내림 조건 `Stop`은 리드에게만 온다. 팀원에게는 `SubagentStop`과 `TeammateIdle`을 같은 뜻으로 쓴다. 합쳐진 서브에이전트의 `SubagentStop`은 서브에이전트가 연 도구와 결정만 닫는다.
- **Ruling P4:** 스펙의 `DecisionKind`는 `permission | question | plan`이지만, 디자인 7.2 표에는 예산·팀원 요청 문장도 있다(스펙 8장이 함께 구현하라고 함). 타입은 5종으로 두고, 서버는 Phase 1에서 3종만 보낸다.
- **Ruling P5 (사용자 확정 2026-10-01):** 라이선스는 **MIT**. 저장소 루트에 `LICENSE`(저작권 "Copyright (c) 2026 gimdong"), `plugin.json`과 `package.json`의 `license`는 `"MIT"`. Galmuri OFL 표시(THIRD_PARTY_NOTICES)는 그대로 둔다. Task 1에서 처리한다.
- **Ruling P6:** 권한 요청 hook이 `AskUserQuestion`·`ExitPlanMode`에 대해 올 때(Phase 0 T0.2), 이미 `PreToolUse`로 올라간 질문·계획 결정의 종류를 `permission`으로 덮어쓰지 않는다.
- **Ruling P7:** 스펙 8장은 결정 대기 책상을 `<button>`(title "결정 보고서는 다음 버전에서 열립니다")으로 두라고 하지만, designer가 디자인 명세 6장 끝 "Phase 1의 결정 대기 캐릭터" 표로 확정한 대로 Phase 1에서는 `<div tabindex="0" role="img" aria-label="{이름}, 결정 필요">`로 두고 `title`, `aria-haspopup`, QRING, pointer 커서를 뺀다(UI는 디자인 명세가 이긴다).
- **Ruling P8:** 디자인 11장의 HUD 칩 aria-label "결정 대기 {N}건, 다음 요청 열기"는 Phase 2 기준이다. Phase 1 칩은 "해당 층으로 스크롤만"(디자인 6장 끝 표) 하므로 aria-label을 "결정 대기 {N}건, 가장 오래 기다린 층으로 이동"으로 둔다. Phase 2에서 원래 문구로 되돌린다.
- **디자인 확인(2026-10-01, designer, SPEC 커밋 0e625f0·c1f8ee4):** 서브에이전트 표시(7.1), 갱신 지연 위치(5.1 FloorHead), 말풍선 우선순위(7.2 끝 "우선순위(확정)"), Phase 1 결정 대기 캐릭터(6장 끝 표), CTX 추정 표시(5.1 미니 바).

```ts
import { execFileSync } from "node:child_process";
import { mkdtemp, readFile, rm } from "node:fs/promises";
import { tmpdir } from "node:os";
import { join } from "node:path";
import { fileURLToPath } from "node:url";
import { afterEach, beforeEach, describe, expect, it } from "vitest";

const ROOT = fileURLToPath(new URL("../..", import.meta.url));
const PLUGIN = join(ROOT, "plugins/claude-office");
const EVENTS = [
  "SessionStart", "SessionEnd", "UserPromptSubmit", "PreToolUse", "PostToolUse", "PostToolUseFailure",
  "PermissionRequest", "PermissionDenied", "Notification", "SubagentStart", "SubagentStop", "TeammateIdle", "Stop",
];
const TOOL_EVENTS = ["PreToolUse", "PostToolUse", "PostToolUseFailure", "PermissionRequest", "PermissionDenied"];

type Hook = { type: string; url: string; timeout: number };
type HookFile = { hooks: Record<string, Array<{ matcher?: string; hooks: Hook[] }>> };
const readJson = async <T>(p: string): Promise<T> => JSON.parse(await readFile(p, "utf8")) as T;
const allHooks = (f: HookFile) => Object.values(f.hooks).flatMap((groups) => groups.flatMap((g) => g.hooks));

describe("marketplace.json", () => {
  it("저장소를 claude-office 마켓플레이스로 만들고 플러그인 폴더를 가리킨다", async () => {
    const m = await readJson<{ name: string; plugins: Array<{ name: string; source: string }> }>(join(ROOT, ".claude-plugin/marketplace.json"));
    expect(m.name).toBe("claude-office");
    expect(m.plugins).toEqual([expect.objectContaining({ name: "claude-office", source: "./plugins/claude-office" })]);
  });
});

describe("plugin.json", () => {
  it("이름, 버전 0.1.0, 설명, MIT 라이선스를 가진다", async () => {
    const p = await readJson<Record<string, unknown>>(join(PLUGIN, ".claude-plugin/plugin.json"));
    expect(p.name).toBe("claude-office");
    expect(p.version).toBe("0.1.0");
    expect(typeof p.description).toBe("string");
    expect(p.license).toBe("MIT");
  });

  it("저장소 LICENSE는 MIT이고 package.json도 MIT다 (Ruling P5)", async () => {
    const text = await readFile(join(ROOT, "LICENSE"), "utf8");
    expect(text.startsWith("MIT License")).toBe(true);
    expect(text).toContain("Copyright (c) 2026 gimdong");
    expect((await readJson<{ license?: string }>(join(ROOT, "package.json"))).license).toBe("MIT");
  });
});

describe("hooks.json", () => {
  it("13개 이벤트를 모두, 그리고 그것만 등록한다", async () => {
    const f = await readJson<HookFile>(join(PLUGIN, "hooks/hooks.json"));
    expect(Object.keys(f.hooks).sort()).toEqual([...EVENTS].sort());
  });

  it("모든 hook은 http 타입, 같은 URL, timeout 5 이하다", async () => {
    const f = await readJson<HookFile>(join(PLUGIN, "hooks/hooks.json"));
    const hooks = allHooks(f);
    expect(hooks).toHaveLength(EVENTS.length);
    for (const h of hooks) {
      expect(h.type).toBe("http");
      expect(h.url).toBe("http://127.0.0.1:4317/hooks/event");
      expect(h.timeout).toBeLessThanOrEqual(5);
    }
  });

  it("도구 이벤트는 matcher '*'를 쓴다", async () => {
    const f = await readJson<HookFile>(join(PLUGIN, "hooks/hooks.json"));
    for (const e of TOOL_EVENTS) expect(f.hooks[e].map((g) => g.matcher)).toEqual(["*"]);
  });
});

describe("make-dev-plugin", () => {
  let tmp: string;
  beforeEach(async () => {
    tmp = await mkdtemp(join(tmpdir(), "claude-office-plugin-"));
  });
  afterEach(() => rm(tmp, { recursive: true, force: true }));

  it("포트만 바꾸고 나머지는 그대로 복사한다", async () => {
    const out = join(tmp, "dev");
```

- [ ] **Step 5: `server/events/summarize.ts` 작성**

```ts
/**
 * hook 입력의 tool_input에서 화면에 필요한 필드만 남긴다(스펙 5장). 원문은 메모리에도 남기지 않는다.
 * 문자열은 코드포인트 기준 MAX_FIELD자까지 자른다 — 서로게이트 쌍을 가르지 않기 위해 Array.from을 쓴다.
 */
export const MAX_FIELD = 200;

export interface ToolSummary {
  command?: string;
  description?: string;
  filePath?: string;
  pattern?: string;
  query?: string;
  domain?: string;
  to?: string;
  /** 문자열: 진행 중 할 일, null: 진행 중 표시를 지움, 없음: 할 일과 무관 */
  activeForm?: string | null;
  question?: string;
}

const cut = (v: unknown): string | undefined =>
  typeof v === "string" && v.trim() ? Array.from(v).slice(0, MAX_FIELD).join("") : undefined;

function domainOf(url: unknown): string | undefined {
  if (typeof url !== "string") return undefined;
  try {
    return cut(new URL(url).hostname);
  } catch {
    return undefined;
  }
}

function activeFormOf(tool: string | undefined, input: Record<string, unknown>): string | null | undefined {
  if (tool === "TodoWrite") {
    const todos = Array.isArray(input.todos) ? input.todos : [];
    const cur = todos.find((t) => (t as { status?: unknown } | null)?.status === "in_progress") as { activeForm?: unknown } | undefined;
    return cut(cur?.activeForm) ?? null;
  }
  if (tool === "TaskUpdate") {
    if (input.status === "in_progress") return cut(input.activeForm);
    if (input.status === "completed" || input.status === "deleted") return null;
  }
  // TaskCreate는 할 일을 대기 상태로 만들 뿐이라 진행 중 표시에 쓰지 않는다(Ruling P2)
  return undefined;
}

export function summarize(toolName: string | undefined, input: unknown): ToolSummary {
  if (!input || typeof input !== "object" || Array.isArray(input)) return {};
  const i = input as Record<string, unknown>;
  const firstQuestion = Array.isArray(i.questions) ? (i.questions[0] as { question?: unknown } | undefined)?.question : undefined;
  const out: ToolSummary = {
    command: cut(i.command),
    description: cut(i.description),
    filePath: cut(i.file_path ?? i.notebook_path),
    pattern: cut(i.pattern),
    query: cut(i.query),
    domain: domainOf(i.url),
    to: cut(i.to),
    activeForm: activeFormOf(toolName, i),
    question: cut(firstQuestion),
  };
  for (const k of Object.keys(out) as (keyof ToolSummary)[]) if (out[k] === undefined) delete out[k];
  return out;
}

export interface AgentRef {
  name: string;
  /** 리드에 합친 일반 서브에이전트 */
  sub: boolean;
  /** 합친 서브에이전트의 agent_type */
  subType?: string;
}

/** 일반 서브에이전트의 agent_id는 a + 16진수다. 팀원은 a<이름>-<해시>라 하이픈이 들어간다(Phase 0 T0.1) */
const SUBAGENT_ID = /^a[0-9a-f]{8,}$/;

/** 이벤트를 어느 캐릭터에 붙일지 정한다. null이면 저장하지 않는다(스펙 2장 3번, 5장). */
export function agentOf(input: Record<string, unknown>): AgentRef | null {
  const event = input.hook_event_name;
  if (event === "TeammateIdle") {
    return typeof input.teammate_name === "string" && input.teammate_name ? { name: input.teammate_name, sub: false } : null;
  }
  const id = input.agent_id;
  if (typeof id !== "string" || !id) return { name: "team-lead", sub: false };
  const type = typeof input.agent_type === "string" ? input.agent_type : "";
  // 턴 뒤에 도는 내부 보조 에이전트는 agent_type이 비어 있다. 캐릭터가 없으므로 버린다
  if (!type && (event === "SubagentStart" || event === "SubagentStop")) return null;
  if (SUBAGENT_ID.test(id)) return type ? { name: "team-lead", sub: true, subType: type } : { name: "team-lead", sub: true };
  return type ? { name: type, sub: false } : null;
}
```

```ts
import { agentOf, summarize, type ToolSummary } from "./summarize";

export interface StoredEvent {
  /** 서버가 받은 시각(ms). hook 입력에는 시각이 없다 */
  at: number;
  event: string;
  sub: boolean;
  /** 합친 서브에이전트의 agent_type */
  subType?: string;
  tool?: string;
  toolUseId?: string;
  summary: ToolSummary;
}

export const PER_AGENT = 20;
const DAY = 86_400_000;

interface SessionBucket {
  agents: Map<string, StoredEvent[]>;
  lastAt: number;
  endedAt?: number;
}

/** hook 이벤트의 요약을 세션·에이전트별 원형 버퍼로 보관한다. 메모리에만 둔다(스펙 5장). */
export class EventStore {
  private readonly sessions = new Map<string, SessionBucket>();

  constructor(private readonly perAgent = PER_AGENT) {}

  /** 검증된 hook 입력 하나를 요약해 저장한다. 저장하지 않았으면 false */
  add(input: Record<string, unknown>, now: number): boolean {
    const sessionId = input.session_id;
    const event = input.hook_event_name;
    if (typeof sessionId !== "string" || typeof event !== "string") return false;
    const agent = agentOf(input);
    if (!agent) return false;

    const tool = typeof input.tool_name === "string" && input.tool_name ? input.tool_name : undefined;
    const toolUseId = typeof input.tool_use_id === "string" && input.tool_use_id ? input.tool_use_id : undefined;
    const e: StoredEvent = {
      at: now,
      event,
      sub: agent.sub,
      ...(agent.subType ? { subType: agent.subType } : {}),
      ...(tool ? { tool } : {}),
      ...(toolUseId ? { toolUseId } : {}),
      summary: summarize(tool, input.tool_input),
    };

    let bucket = this.sessions.get(sessionId);
    if (!bucket) {
      bucket = { agents: new Map(), lastAt: now };
      this.sessions.set(sessionId, bucket);
    }
    bucket.lastAt = now;
    if (event === "SessionEnd") bucket.endedAt = now;
    const list = bucket.agents.get(agent.name) ?? [];
    list.push(e);
    if (list.length > this.perAgent) list.splice(0, list.length - this.perAgent);
    bucket.agents.set(agent.name, list);
    return true;
  }

  agents(sessionId: string): ReadonlyMap<string, readonly StoredEvent[]> {
    return this.sessions.get(sessionId)?.agents ?? new Map();
  }

  /** 세션이 끝난 뒤(끝난 적이 없으면 마지막 이벤트 뒤) 24시간이 지난 세션을 버린다 */
  prune(now: number): void {
    for (const [id, b] of this.sessions) if (now - (b.endedAt ?? b.lastAt) > DAY) this.sessions.delete(id);
  }

  sessionCount(): number {
    return this.sessions.size;
  }
}
```

```ts
import type { Activity, Decision, DecisionKind } from "../../src/shared/types";
import type { StoredEvent } from "./store";
import type { ToolSummary } from "./summarize";

export const TOOL_TTL = 10 * 60_000;
export const DECISION_TTL = 30 * 60_000;

export interface Derived {
  activity?: Activity;
  decision?: Decision;
  /** 이벤트로 확인된 작업 중(짝 없는 PreToolUse가 10분 안에 있음). v1 파일 판정보다 우선한다 */
  toolRunning: boolean;
}

const iso = (ms: number) => new Date(ms).toISOString();

/** 말풍선 「」 안에 들어갈 원문을 도구별로 고른다(디자인 7.2). 모르는 도구는 undefined — UI가 도구 이름을 쓴다 */
export function targetOf(tool: string | undefined, s: ToolSummary): string | undefined {
  switch (tool) {
    case "Bash":
      return s.description ?? s.command;
    case "Edit":
    case "MultiEdit":
    case "NotebookEdit":
    case "Write":
    case "Read":
      return s.filePath;
    case "Grep":
    case "Glob":
      return s.pattern;
    case "WebSearch":
      return s.query;
    case "WebFetch":
      return s.domain;
    case "SendMessage":
      return s.to;
    case "Agent":
    case "Task":
      return s.description;
    default:
      return undefined;
  }
}

function decisionKindOf(tool: string | undefined): DecisionKind {
  if (tool === "AskUserQuestion") return "question";
  if (tool === "ExitPlanMode") return "plan";
  return "permission";
}

function decisionSummary(kind: DecisionKind, e: StoredEvent): string | undefined {
  if (kind === "question") return e.summary.question;
  if (kind === "permission") return e.summary.command ?? e.summary.filePath ?? e.tool;
  return undefined;
}

interface Pending {
  at: number;
  tool?: string;
  toolUseId?: string;
  sub: boolean;
  subType?: string;
  target?: string;
}

interface Raised {
  kind: DecisionKind;
  at: number;
  tool?: string;
  sub: boolean;
  summary?: string;
}

const TURN_END = new Set(["Stop", "SubagentStop", "TeammateIdle", "SessionEnd"]);
const CLOSES_TOOL = new Set(["PostToolUse", "PostToolUseFailure", "PermissionDenied"]);

export function deriveAgent(events: readonly StoredEvent[], now: number): Derived {
  let pending: Pending[] = [];
  let decision: Raised | undefined;
  let todo: { text: string; at: number } | undefined;

  const raise = (e: StoredEvent) => {
    const kind = decisionKindOf(e.tool);
    decision = { kind, at: e.at, tool: e.tool, sub: e.sub, summary: decisionSummary(kind, e) };
  };

  for (const e of events) {
    if (e.event === "PreToolUse") {
      decision = undefined; // 새 도구 호출이 시작되면 앞선 결정은 끝났다
      pending.push({ at: e.at, tool: e.tool, toolUseId: e.toolUseId, sub: e.sub, subType: e.subType, target: targetOf(e.tool, e.summary) });
      if (e.tool === "AskUserQuestion" || e.tool === "ExitPlanMode") raise(e);
      if (e.summary.activeForm !== undefined) todo = e.summary.activeForm === null ? undefined : { text: e.summary.activeForm, at: e.at };
    } else if (CLOSES_TOOL.has(e.event)) {
      const i = e.toolUseId ? pending.findIndex((p) => p.toolUseId === e.toolUseId) : pending.findIndex((p) => !p.toolUseId);
      if (i >= 0) pending.splice(i, 1); // 짝이 없는 Post는 무시한다
      decision = undefined;
    } else if (e.event === "PermissionRequest") {
      // 질문·계획은 PreToolUse에서 이미 올라가 있다. 같은 도구의 권한 요청이 종류를 덮어쓰지 않게 한다(Ruling P6)
      if (!(decision && decision.tool === e.tool)) raise(e);
    } else if (TURN_END.has(e.event)) {
      // 합쳐진 서브에이전트가 끝나면 그 서브에이전트가 연 것만 닫는다(Ruling P3)
      pending = e.sub ? pending.filter((p) => !p.sub) : [];
      if (!e.sub || decision?.sub) decision = undefined;
    }
  }

  const live = pending.filter((p) => now - p.at <= TOOL_TTL);
  const cur = live.at(-1);
  const out: Derived = { toolRunning: live.length > 0 };
  if (cur) {
    out.activity = {
      kind: "tool",
      ...(cur.tool ? { tool: cur.tool } : {}),
      ...(cur.target ? { target: cur.target } : {}),
      startedAt: iso(cur.at),
      ...(cur.sub ? { sub: true } : {}),
      ...(cur.sub && cur.subType ? { subType: cur.subType } : {}),
    };
  } else if (todo) {
    out.activity = { kind: "todo", target: todo.text, startedAt: iso(todo.at) };
  }
  if (decision && now - decision.at <= DECISION_TTL) {
    out.decision = { kind: decision.kind, since: iso(decision.at), ...(decision.summary ? { summary: decision.summary } : {}) };
  }
  return out;
}
```

```ts
/** 대화 기록 마지막 항목이 assistant 텍스트면 그 마지막 문장(최대 200자). "저는 방금 「…」라고 말했습니다"에 쓴다 */
export function lastSentence(entry: unknown): string | undefined {
  const e = entry as { type?: string; message?: { content?: unknown } } | undefined;
  if (e?.type !== "assistant" || !Array.isArray(e.message?.content)) return undefined;
  const text = e.message.content
    .filter((c): c is { type: "text"; text: string } => (c as { type?: unknown } | null)?.type === "text" && typeof (c as { text?: unknown }).text === "string")
    .map((c) => c.text)
    .join(" ")
    .trim();
  if (!text) return undefined;
  const last = text.split(/(?<=[.!?。])\s+|\n+/).map((p) => p.trim()).filter(Boolean).at(-1);
  return last === undefined ? undefined : Array.from(last).slice(0, 200).join("");
}
```

```tsx
/** 7×7 도트 아이콘을 14×14로 그린다. 뜻은 옆 글자나 버튼의 aria-label로 전한다(디자인 4.5) */

  return (
    <svg className="px icon" viewBox="0 0 7 7" width={14} height={14} shapeRendering="crispEdges" aria-hidden="true">

    </svg>
  );
}
```

```ts
import type { DecisionKind, Member } from "../../src/shared/types";
import { formatTokens } from "../format";
import type { IconName } from "../pixel/sprites";

/** 「」 안 값의 최대 글자 수(디자인 7.3) */
export const CLIP = 28;

const SEGMENTER: Intl.Segmenter | undefined =
  typeof Intl !== "undefined" && "Segmenter" in Intl ? new Intl.Segmenter("ko", { granularity: "grapheme" }) : undefined;

/** 글자 단위로 나눈다. Segmenter가 없으면 코드포인트 단위로 대체한다 */
export function chars(s: string, segmenter: Intl.Segmenter | undefined = SEGMENTER): string[] {
  return segmenter ? Array.from(segmenter.segment(s), (x) => x.segment) : Array.from(s);
}

export function squash(s: string): string {
  return s.replace(/\s+/g, " ").trim();
}

export function clipEnd(s: string, n = CLIP): string {
  const c = chars(squash(s));
  return c.length <= n ? c.join("") : c.slice(0, n - 1).join("") + "…";
}

/** 가운데를 "…"로 줄여 앞부분과 확장자를 살린다. 예: 2026-09-28-cla…ice-design.md */
export function clipMiddle(s: string, n = CLIP): string {
  const c = chars(squash(s));
  if (c.length <= n) return c.join("");
  const head = Math.ceil((n - 1) / 2);
  const tail = Math.floor((n - 1) / 2);
  return c.slice(0, head).join("") + "…" + c.slice(c.length - tail).join("");
}

export function fileName(path: string): string {
  return path.split(/[\\/]/).filter(Boolean).at(-1) ?? path;
}

export interface Line {
  icon: IconName;
  text: string;
  /** 결정 대기 문장이면 말풍선 테두리를 노랑으로 바꾼다 */
  decision: boolean;
}

// 조사가 받침에 따라 바뀌지 않도록 변하는 값은 「」로 감싸고 뒤에 고정 명사를 붙인다(디자인 7.2)
const q = (s: string) => `「${clipEnd(s)}」`;
const qf = (path: string) => `「${clipMiddle(fileName(path))}」`;
const line = (icon: IconName, text: string, decision = false): Line => ({ icon, text, decision });

const WAITING_FOR: Record<DecisionKind, string> = {
  permission: "명령 실행 허락을",
  question: "질문에 대한 답을",
  plan: "계획 승인을",
  budget: "예산 추가 여부를",
  team: "팀 리드의 결정을",
};

const other = (tool: string) => line("bash", `저는 지금 ${q(tool || "알 수 없는")} 도구를 쓰고 있습니다`);

function toolLine(tool = "", target?: string): Line {
  // 요약 필드가 비어 대상이 없으면 "그 밖의 도구" 틀을 쓴다(스펙 9장)
  if (target === undefined) return other(tool);
  switch (tool) {
    case "Bash":
      return line("bash", `저는 지금 ${q(target)} 명령을 실행하고 있습니다`);
    case "Edit":
    case "MultiEdit":
    case "NotebookEdit":
      return line("edit", `저는 지금 ${qf(target)} 파일을 고치고 있습니다`);
    case "Write":
      return line("edit", `저는 지금 ${qf(target)} 파일을 만들고 있습니다`);
    case "Read":
      return line("read", `저는 지금 ${qf(target)} 파일을 읽고 있습니다`);
    case "Grep":
    case "Glob":
      return line("search", `저는 지금 ${q(target)} 패턴을 찾고 있습니다`);
    case "WebSearch":
      return line("web", `저는 지금 ${q(target)} 자료를 찾아보고 있습니다`);
    case "WebFetch":
      return line("web", `저는 지금 ${q(target)} 페이지를 읽고 있습니다`);
    case "SendMessage":
      return line("team", `저는 지금 ${clipEnd(target)}에게 메시지를 보내고 있습니다`);
    case "Agent":
    case "Task":
      return line("team", `저는 지금 ${q(target)} 일을 맡기고 있습니다`);
    default:
      return other(tool);
  }
}

/** 디자인 7.2 표. 우선순위: 결정 → 휴업 → 퇴근 → 도구 → activeForm → 메시지 → 마지막 문장 → 대기 */
export function activityLine(m: Member, opts: { paused?: boolean } = {}): Line {
  if (m.state === "decision" && m.decision) return line("ask", `저는 지금 ${WAITING_FOR[m.decision.kind]} 기다리고 있습니다`, true);
  if (opts.paused) return line("pause", "저는 지금 휴업 중이라 쉬고 있습니다");
  if (m.state === "offline") return line("wait", "저는 퇴근했습니다");
  const a = m.activity;
  if (a?.kind === "tool") return toolLine(a.tool, a.target);
  if (a?.kind === "todo" && a.target) return line("read", `저는 지금 할 일 목록의 ${q(a.target)} 항목을 진행하고 있습니다`);
  if (m.unread > 0) return line("team", `저는 지금 읽지 않은 메시지가 ${m.unread}통 있습니다`);
  if (a?.kind === "said" && a.target) return line("team", `저는 방금 ${q(a.target)}라고 말했습니다`);
  return line("wait", "저는 지금 다음 지시를 기다리고 있습니다");
}

/** 보조 줄(디자인 7.1): {모델} · 토큰 {n} · {경과}초째. 결정 대기와 퇴근은 따로 */
export function metaLine(m: Member, now: number): string {
  if (m.state === "decision") return "결정 보고서는 다음 버전에서 열립니다";
  if (m.state === "offline") return "";
  const parts: string[] = [];
  // 디자인 7.1: 리드에 합친 서브에이전트가 한 일이면 앞머리에 "서브에이전트" 또는 "서브에이전트({agent_type})"
  if (m.activity?.sub) parts.push(m.activity.subType ? `서브에이전트(${m.activity.subType})` : "서브에이전트");
  if (m.model) parts.push(m.model);
  parts.push(`토큰 ${formatTokens(m.tokens.total)}`);
  if (m.activity && m.activity.kind !== "said") {
    const secs = Math.floor((now - Date.parse(m.activity.startedAt)) / 1000);
    if (Number.isFinite(secs) && secs >= 0) parts.push(`${secs}초째`);
  }
  return parts.join(" · ");
}
```

```ts
// 읽기·쓰기 모두 예외를 삼킨다(v1의 localStorage 원칙).
const key = (id: string) => `claude-office:fold:${id}`;

export function readFold(id: string, fallback: boolean): boolean {
  try {
    const v = localStorage.getItem(key(id));
    return v === null ? fallback : v === "1";
  } catch {
    return fallback;
  }
}

export function writeFold(id: string, collapsed: boolean): void {
  try {
    localStorage.setItem(key(id), collapsed ? "1" : "0");
  } catch {
    // 기억하지 못해도 이번 화면에서는 접힘이 유지된다
  }
}
```

```tsx
/** 층 머리의 작은 바(디자인 5.1 미니 바, A3). 남은 양 %를 보여준다 */
export function MiniBar({ label, remaining, noneText, hint }: { label: string; remaining: number | null; noneText: string; hint?: string }) {
  if (remaining === null) {
    return (
      <span className="mini none">
        {label} <span className="val">{noneText}</span>
      </span>
    );
  }
  // 색과 표시 숫자를 같은 반올림 값으로 정해 경계(49.6 → "50%"인데 노랑)가 어긋나지 않게 한다
  const v = Math.round(remaining);
  const level = barLevel(v);
  return (
    <span
      className={`mini${level === "ok" ? "" : ` ${level}`}`}
      role="meter"
      aria-label={hint ? `${label} 남은 양 (${hint})` : `${label} 남은 양`}
      aria-valuemin={0}
      aria-valuemax={100}
      aria-valuenow={v}
    >
      {label}
      <span className="track">
        <span className="fill" style={{ width: `${v}%` }} />
      </span>
      <span className="val">{v}%</span>
      {hint && <span className="hint">{hint}</span>}
    </span>
  );
}
```

```tsx
function hhmm(iso?: string): string {
  if (!iso) return "";
  const d = new Date(iso);
  if (!Number.isFinite(d.getTime())) return "";
  return `${String(d.getHours()).padStart(2, "0")}:${String(d.getMinutes()).padStart(2, "0")}`;
```

```ts
import type { Member, SessionView } from "../../src/shared/types";
import { floorDomId } from "../building/Floor";

export function decisionQueue(sessions: SessionView[]): Array<{ session: SessionView; member: Member }> {
  return sessions
    .flatMap((session) => session.members.filter((m) => m.state === "decision" && m.decision).map((member) => ({ session, member })))
    .sort((a, b) => Date.parse(a.member.decision!.since) - Date.parse(b.member.decision!.since));
}

const reduceMotion = () => typeof matchMedia === "function" && matchMedia("(prefers-reduced-motion: reduce)").matches;

/** 층으로 스크롤한다(디자인 5.5). "fold"면 그 층의 접기 버튼에 포커스를 준다 */
export function goToFloor(sessionId: string, focus: "fold" | "none" = "fold"): void {
  const floor = document.getElementById(floorDomId(sessionId));
  if (!floor) return;
  floor.scrollIntoView?.({ block: "start", behavior: reduceMotion() ? "auto" : "smooth" });
  if (focus === "fold") floor.querySelector<HTMLElement>(".fold")?.focus({ preventScroll: true });
}
```

```ts
import { useEffect, useRef, useState } from "react";
import type { Snapshot } from "../src/shared/types";

/** 새 결정이 생기면 스크린 리더에 한 번 알릴 문장(디자인 11장 HUD 결정 칩) */
export function useDecisionAnnouncer(snapshot: Snapshot | null): string {
  const seen = useRef<Set<string> | null>(null);
  const [message, setMessage] = useState("");
  useEffect(() => {
    if (!snapshot) return;
    const now = new Map<string, string>();
    for (const s of snapshot.sessions)
      for (const m of s.members) if (m.state === "decision" && m.decision) now.set(`${s.id}:${m.name}:${m.decision.since}`, `${s.floor}F ${m.name}이(가) 결정을 기다립니다`);
    const prev = seen.current;
    seen.current = new Set(now.keys());
    if (!prev) return; // 첫 스냅샷은 알리지 않는다(이미 있던 결정)
    const fresh = [...now].find(([k]) => !prev.has(k));
    if (fresh) setMessage(fresh[1]);
  }, [snapshot]);
  return message;
}
```

```ts
export interface PlaceInput {
  deskLeft: number;
  deskTop: number;
  w: number;
  h: number;
  viewportW: number;
  hudBottom: number;
}

export interface Placement {
  left: number;
  top: number;
  below: boolean;
  tailX: number;
}

/** 디자인 7.4: 캐릭터 중심 = 책상 왼쪽 + 36px, 머리 위 = 책상 위쪽 + 28px */
export function placeBubble(i: PlaceInput): Placement {
  const cx = i.deskLeft + 36;
  const left = Math.min(Math.max(8, cx - i.w / 2), i.viewportW - i.w - 8);
  let top = i.deskTop + 28 - i.h - 10;
  const below = top < i.hudBottom + 4;
  if (below) top = i.deskTop + 86;
  const tailX = Math.min(Math.max(12, cx - left), i.w - 12);
  return { left, top, below, tailX };
}
```

```ts
import { useEffect, useMemo, useRef, useState } from "react";
import type { BubbleHandlers } from "./types";

export interface BubbleTarget {
  el: HTMLElement;
  key: string;
}

/** 디자인 7.5: 진입 150ms 뒤 표시(이미 보이면 즉시 바꿈), 이탈 100ms 뒤 숨김, 포커스 즉시, Esc·스크롤 숨김 */
export function useBubble(): { target: BubbleTarget | null; handlers: BubbleHandlers } {
  const [target, setTarget] = useState<BubbleTarget | null>(null);
  const shown = useRef(false);
  const timer = useRef<ReturnType<typeof setTimeout> | undefined>(undefined);

  const handlers = useMemo<BubbleHandlers>(() => {
    const clear = () => clearTimeout(timer.current);
    const show = (el: HTMLElement, key: string) => {
      shown.current = true;
      setTarget({ el, key });
    };
    const hide = () => {
      shown.current = false;
      setTarget(null);
    };
    return {
      enter(el, key) {
        clear();
        if (shown.current) show(el, key);
        else timer.current = setTimeout(() => show(el, key), 150);
      },
      leave() {
        clear();
        timer.current = setTimeout(hide, 100);
      },
      focus(el, key) {
        clear();
        show(el, key);
      },
      blur() {
        clear();
        hide();
      },
    };
  }, []);

  useEffect(() => {
    const hideNow = () => {
      clearTimeout(timer.current);
      shown.current = false;
      setTarget(null);
    };
    const onKey = (e: KeyboardEvent) => {
      if (e.key === "Escape") hideNow();
    };
    window.addEventListener("keydown", onKey);
    window.addEventListener("scroll", hideNow, { capture: true, passive: true });
    return () => {
      window.removeEventListener("keydown", onKey);
      window.removeEventListener("scroll", hideNow, { capture: true });
      clearTimeout(timer.current);
    };
  }, []);

  return { target, handlers };
}
```

```tsx
import { useEffect, useLayoutEffect, useRef, useState } from "react";
import type { Member, SessionView } from "../../src/shared/types";
import { activityLine, metaLine } from "../office/activityText";
import { Icon } from "../pixel/Icon";
import { NEON } from "../pixel/palette";
import { placeBubble, type Placement } from "./place";
import type { BubbleTarget } from "./useBubble";

function findMember(sessions: SessionView[], key: string): Member | undefined {
  const i = key.indexOf(":");
  const sessionId = key.slice(0, i);
  const name = key.slice(i + 1);
  return sessions.find((s) => s.id === sessionId)?.members.find((m) => m.name === name);
}

/** 모든 책상이 함께 쓰는 fixed 말풍선 하나(디자인 7.1). 등장 애니메이션은 없다 */
export function ActivityBubble({ target, sessions }: { target: BubbleTarget | null; sessions: SessionView[] }) {
  const ref = useRef<HTMLDivElement>(null);
  const [place, setPlace] = useState<Placement | null>(null);
  const [now, setNow] = useState(() => Date.now());
  const member = target ? findMember(sessions, target.key) : undefined;
  const line = member ? activityLine(member) : undefined;
  const meta = member ? metaLine(member, now) : "";

  // "{경과}초째"가 흐르도록 보이는 동안 1초마다 다시 그린다
  useEffect(() => {
    if (!target) return;
    setNow(Date.now());
    const t = setInterval(() => setNow(Date.now()), 1000);
    return () => clearInterval(t);
  }, [target]);

  useEffect(() => {
    if (!target || !member) return;
    target.el.setAttribute("aria-describedby", "say");
    return () => target.el.removeAttribute("aria-describedby");
  }, [target, member]);

  // 내용이 바뀌면(SSE) 위치를 다시 계산한다(디자인 7.5)
  useLayoutEffect(() => {
    if (!target || !ref.current) return;
    const r = target.el.getBoundingClientRect();
    const hudBottom = document.querySelector(".hud")?.getBoundingClientRect().bottom ?? 0;
    setPlace(placeBubble({ deskLeft: r.left, deskTop: r.top, w: ref.current.offsetWidth, h: ref.current.offsetHeight, viewportW: window.innerWidth, hudBottom }));
  }, [target, line?.text, meta]);

  if (!target || !member || !line) return null;
  return (
    <div
      ref={ref}
      id="say"
      role="tooltip"
      className={`say${line.decision ? " q" : ""}${place?.below ? " below" : ""}`}
      style={place ? { left: place.left, top: place.top } : { left: -9999, top: 0 }}
    >
      <div className="line">
        <Icon name={line.icon} ink={line.decision ? NEON.yellow : NEON.cyan} accent={line.decision ? NEON.yellow : NEON.green} />
        <span className="text">{line.text}</span>
      </div>
      <div className="meta">{meta}</div>
      <span className="tail" style={{ left: place?.tailX ?? 12 }} />
    </div>
  );
}
```
