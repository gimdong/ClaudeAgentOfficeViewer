# v2 Phase 5 공개 배포 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 공개 배포를 위해 Linux 같은 계정 검사, 플러그인 버전 불일치 경고, 영어 문서, 관리자 안내를 더한다.

**Architecture:** 4317 서버에 Host 검사 바로 뒤 미들웨어(`server/peer.ts`)를 하나 둔다. hooks.json의 정적 헤더로 플러그인 버전을 받아 스냅샷·HUD에 보인다. 문서는 코드와 독립.

**Tech Stack:** Node(표준 모듈), Express 5, React, Vitest.

**Spec:** `docs/superpowers/specs/2026-10-18-v2-phase5-design.md`

## Global Constraints
- 새 의존성 없음.
- 거절 응답 본문: `같은 사용자 계정의 프로그램만 접속할 수 있습니다`
- doctor 문구: `다른 계정의 접속 {n}건을 막았습니다. 여러 사람이 쓰는 컴퓨터라면 정상입니다.`
- HUD 칩: `플러그인 {version} ≠ 서버 {서버 버전} — 같은 압축 파일로 다시 설치하세요` / unknown이면 `플러그인 버전 모름`
- 헤더 이름: `X-Claude-Office-Plugin`
- 로그에 uid·포트 값을 적지 않는다.
- 검사는 `process.platform === "linux"`에서만.

## Review Focus
1. 판정 실패(줄 없음·읽기 오류)는 반드시 거절이어야 한다 — 통과로 새면 보안 구멍.
2. 미들웨어가 `/hooks/event`의 기존 403/415 카운트와 겹쳐 두 번 세지 않아야 한다.
3. IPv6(`[::1]`) 접속도 tcp6에서 찾아야 한다 — tcp만 보면 localhost가 ::1로 풀리는 환경에서 전부 거절.
4. 서버 포트는 고정 4317이 아니라 실제 listen 포트(`req.socket.localPort`)로 비교해야 한다(테스트·설치 확인은 다른 포트를 쓴다).
5. 헤더 없는 옛 플러그인에서 hook 처리 자체가 깨지면 안 된다(경고만).

```ts
import type { RequestHandler } from "express";
import type { Socket } from "node:net";
import { readFileSync } from "node:fs";

const port = (addr: string) => parseInt(addr.slice(addr.lastIndexOf(":") + 1), 16);

/** /proc/net/tcp(6) 텍스트에서 클라이언트 쪽 연결(local=clientPort, rem=serverPort)의 uid. 없으면 null */
export function peerUidFromProc(tcp: string, tcp6: string, clientPort: number, serverPort: number): number | null {
  for (const line of `${tcp}\n${tcp6}`.split("\n")) {
    const c = line.trim().split(/\s+/);
    if (c.length < 8 || !c[0].endsWith(":")) continue;
    if (port(c[1]) === clientPort && port(c[2]) === serverPort) return Number(c[7]);
  }
  return null;
}

export function sameUserGuard(o: { platform?: string; uid?: number; read?: (p: string) => string; onReject?: () => void } = {}): RequestHandler {
  const platform = o.platform ?? process.platform;
  const uid = o.uid ?? process.getuid?.();
  const read = o.read ?? ((p: string) => readFileSync(p, "utf8"));
  const seen = new WeakMap<Socket, boolean>();
  return (req, res, next) => {
    if (platform !== "linux" || uid === undefined) return next();
    const s = req.socket;
    let ok = seen.get(s);
    if (ok === undefined) {
      try {
        ok = peerUidFromProc(read("/proc/net/tcp"), read("/proc/net/tcp6"), s.remotePort ?? -1, s.localPort ?? -1) === uid;
      } catch {
        ok = false;
      }
      seen.set(s, ok);
    }
    if (ok) return next();
    o.onReject?.();
    res.status(403).type("text/plain").send("같은 사용자 계정의 프로그램만 접속할 수 있습니다");
  };
}
```
tcp6이 없는 커널(IPv6 꺼짐)을 위해 tcp6 읽기 실패만은 빈 문자열로 처리한다(tcp 읽기 실패는 거절).
