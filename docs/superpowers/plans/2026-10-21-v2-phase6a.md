# v2 Phase 6a Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 13개 hook을 AES-256-GCM 암호화 command relay로 바꿔 Critical-1 hook 쪽을 닫고, 원격 보기 1단계(`claude-office url`)를 더한다.

**Architecture:** 플러그인 `hooks/relay.cjs`(node 내장만)가 stdin 이벤트를 `<PREFIX>/hook.key`에서 HKDF로 만든 방향별 키로 암호화해 `POST /hooks/v2`로 한 번 보내고, 서버는 풀어 기존 hook 처리기에 넘긴 뒤 결과를 암호화해 돌려준다. 실패는 모두 무출력 exit 0. 옛 `/hooks/event`는 beta.14 동안 legacy로 받는다.

**Tech Stack:** Node(내장 crypto·net), Express 5, React, Vitest.

**Spec:** `docs/superpowers/specs/2026-10-21-v2-phase6a-design.md` · 근거 `docs/superpowers/spikes/2026-10-21-phase6a-spike.md`

## Global Constraints
- 새 의존성 없음. relay는 CommonJS 단일 파일, `node:crypto`·`node:net`·`node:fs`만.
- relay 출력 안전 규칙(스펙 3장 7번): 모든 실패 exit 0 + 빈 stdout, exit 1·2 금지, 문맥 주입 이벤트 5종은 출력 안 함.
- hooks.json 명령은 exec form(`command` + `args`), `command`는 설치 때 적은 node 절대 경로, `onFailure` 없음.
- 열쇠·평문·토큰을 로그·스냅샷·진단·커밋에 쓰지 않는다. 테스트는 가짜 열쇠만.
- 사용자 4317·설치본·`~/.claude` 접근 금지, 시험은 4320 이상 포트·임시 HOME. install.sh를 시험할 때는 `--port <시험 포트>`(Task 4 뒤) 또는 doctor 건너뛰기(B279).
- 칩 문구: `옛 플러그인(http hook)이 남아 있습니다 — 같은 압축 파일로 다시 설치하세요`
- doctor 문구(node): `hook을 실행할 node가 없습니다(nvm 등으로 바뀜) — 다시 설치하세요`
- 커밋 전 `git diff --cached --stat`(B249).

## Review Focus
1. 어떤 실패도 허용이나 exit 2로 새지 않아야 한다(fail-open·서비스 거부 둘 다 금지).
2. 가짜 서버·중계자에게 평문이 0바이트여야 한다(GCM 키 방향 분리, kid만 평문).
3. 재전송 창: 같은 id 두 번째 401, ts 범위 밖 401, 상한 넘으면 오래된 것부터 버림(메모리 상한).
4. 설치 스크립트가 자리 표시자를 못 바꾸면 반드시 실패해야 한다(맨 `__NODE__`가 남은 플러그인은 모든 hook이 조용히 실패).
5. PermissionRequest 대기 중 relay가 끝나면 서버가 결정을 닫아야 한다(터미널 먼저 답하기 유지).

### Task 1: 서버 `/hooks/v2`와 열쇠 파일 (developer)
**Files:** Create `server/hooks/v2.ts`(복호화·형식·재전송 창, 순수 함수 + 미들웨어), `test/server/hooks-v2.test.ts`. Modify `server/app.ts`(라우트, 기존 `/hooks/event` 처리 함수를 공용으로 빼서 둘이 부름), `server/index.ts`(열쇠 파일 생성·검사), `server/events/stats.ts`, `src/shared/types.ts`(rejected `401-v2`, `plugin.legacy`).
**Interfaces:** Produces `deriveKeys(key: Buffer): { req: Buffer; res: Buffer; kid: string }`(HKDF-SHA256, info `"claude-office hook req v1"`/`"… res v1"`), `openRequest(body, keys, now, seen): { ok: true; id: string; plugin: string; event: unknown } | { ok: false; reason: string }`, `sealResponse(id, out, keys): { iv; ct; tag }`. relay(Task 2)도 같은 HKDF info·필드 이름을 쓴다.
- [ ] RED: 정상 왕복, kid 틀림, 1비트 변조, ts ±31초, 같은 id 두 번, 상한 10,000 초과 시 가장 오래된 것 제거, 본문 1MB 초과, iv 길이 ≠12·tag ≠16 → 모두 401 빈 본문. PermissionRequest 대기 중 연결 끊김 → 결정 닫힘. 옛 `/hooks/event` 수신 → snapshot `plugin.legacy === true`.
- [ ] 구현 → typecheck·관련 테스트 → 변이(재전송 검사 빼기, ts 검사 빼기, 키 방향 바꾸기) → 커밋 `feat(server): encrypted /hooks/v2 with replay window, hook key file (Phase 6a §4)`
