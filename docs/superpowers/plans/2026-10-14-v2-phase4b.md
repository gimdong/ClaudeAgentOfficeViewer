# v2 Phase 4b — 작업 지시·새 층(실험 기능) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 대시보드가 channel을 붙인 새 층을 tmux로 띄우고, 그 층에 작업을 지시하며, 휴업 중 지시는 보관했다가 재개 브리핑에서 고쳐 보낸다.

**Architecture:** 플러그인에 의존성 없는 stdio MCP channel 서버(`plugins/claude-office/channel/server.mjs`)를 넣는다. 이 서버는 포트를 열지 않고, 층 열쇠가 env에 있을 때만 4317 `/channel/stream`(SSE)에 나가는 연결을 건다. 서버 쪽 `server/floors/channels.ts`가 launched·연결·보관함·실험 스위치를 들고, `server/floors/launch.ts`가 `tmux`를 인자 배열로 실행한다. 화면은 스냅샷의 `SessionView.channel`만 보고 그린다.

**Tech Stack:** Node 24 ESM, TypeScript, Express 5, React 19, Vitest, jsdom.

**Spec:** `docs/superpowers/specs/2026-10-14-v2-phase4b-design.md` (1d2c8ce)

## Global Constraints
- 브랜치 `feat/v2-phase4b`(main f7d04db 위). push·merge·태그는 사용자 지시 후에만.
- 실행 파일은 `tmux`와 서버 시작 때 확인한 claude 절대 경로뿐, 셸 없음. 첫 지시는 channel 옵션 **앞**.
- channel 서버는 포트를 열지 않는다. `process.env`에서 `CLAUDE_OFFICE_FLOOR_KEY`, `CLAUDE_OFFICE_PORT`만 읽는다. 열쇠 없으면 무연결·무출력.
- 층 열쇠·지시 글·폴더 경로는 로그·진단·스냅샷에 넣지 않는다.
- 상한: 띄운 층 8, 층당 보관 20, 지시 8,000자.
- 실험 스위치는 `~/.claude-office/experimental.json`(0600, 원자적 쓰기)에 저장한다 — 스펙 §3의 "state.json과 같은 파일"을 B160으로 바꿈: 예산 저장소의 형식을 건드리지 않으려고 따로 둔다.
- 실제 세션 확인은 job tmp·4319 이상·`tmux -L p4bt`, 프롬프트 4개 이하, 사용자 4317과 그 세션은 대상 아님.

## Review Focus
1. 열쇠 없는 평범한 세션에서 channel 서버가 연결·출력을 하면 모든 세션이 영향을 받는다 → 무연결 테스트.
2. 지시 글에 따옴표·`$()`·줄바꿈이 있어도 그대로 한 인자 → 인자 배열 테스트.
3. 휴업 중 보낸 지시가 바로 나가면 도구 거부만 쌓인다 → held 상태 테스트.
4. 재개 브리핑에서 [취소]하면 휴업 유지·보관 유지.
5. channel 연결이 끊긴 층에 지시를 보내면 조용히 사라지면 안 된다 → 409 `not-connected`.
